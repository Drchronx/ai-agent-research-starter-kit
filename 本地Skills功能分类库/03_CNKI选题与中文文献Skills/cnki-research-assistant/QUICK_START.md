# 🚀 一键式选题分析 - 快速开始

## 使用方法

### 方式一：全自动分析（推荐）

```bash
# 一句话完成所有分析
python scripts/auto_analyzer.py "你的选题关键词"
```

**示例：**
```bash
python scripts/auto_analyzer.py "数字经济"
```

**自动完成：**
1. ✅ 检查数据库文献数量
2. ✅ 自动抓取缺失文献（多排序：热点/权威/最新/综合）
3. ✅ 深度分析（热榜 + 趋势 + 文献 + 期刊 + 研究空白）
4. ✅ 生成 Markdown 报告
5. ✅ 创建飞书文档并插入图表

**输出：**
- 本地报告：`reports/auto/数字经济_分析报告_时间戳.md`
- 图表目录：`reports/auto/charts/`
- 飞书文档：自动生成链接

---

### 方式二：快速分析（已有足够文献时）

```bash
# 跳过文献抓取，直接分析
python scripts/auto_analyzer.py "数字经济" --no-crawl
```

适用场景：数据库中已有足够文献（>200 篇）

---

### 方式三：指定输出目录

```bash
# 输出到指定目录
python scripts/auto_analyzer.py "数字经济" --output-dir /path/to/output
```

## 预计耗时

| 步骤 | 耗时 |
|------|------|
| 文献抓取 | 5-10 分钟（4 种排序 × 3 页） |
| 深度分析 | 2-3 分钟 |
| 飞书文档 | 1-2 分钟 |
| **总计** | **8-15 分钟** |

## 分析报告包含

### 1. 热点扫描
- CNKI 热榜排名（周榜/月榜）
- 在榜天数和状态

### 2. 趋势评估
- 年度趋势图（峰值年份、近三年占比）
- 学科分布图
- 期刊分布图
- 机构分布图
- 基金分布图
- 主要主题图

### 3. 文献调研
- 高被引文献 Top 10
- 核心作者识别
- 研究方法分析（实证/理论/案例等）

### 4. 期刊推荐
- CSSCI 期刊匹配度 Top 10
- 期刊征稿方向契合点
- 投稿策略建议

### 5. 研究空白分析（6 个维度）
- 关键词共现空白
- 主题聚类空白
- 研究方法空白
- 机构合作空白
- 基金资助空白
- 时间趋势空白

### 6. 综合建议
- 选题可行性评估
- 潜在切入点
- 投稿策略

## 故障排查

### 问题 1：文献抓取失败

**症状**：抓取结果为 0

**解决**：
1. 检查代理配置：`python /root/.openclaw/skills/cnki-crawler/scripts/proxy_check.py`
2. 验证检索式：`python /root/.openclaw/skills/cnki-crawler/scripts/validate_query.py "SU=('数字经济')"`

### 问题 2：飞书文档创建失败

**症状**：报告生成成功，但飞书文档创建失败

**解决**：
1. 检查飞书授权状态
2. 手动创建文档，复制报告内容

### 问题 3：图表中文乱码

**症状**：图表中文字符显示为方框

**解决**：
字体文件已配置为 `data/STSONG.TTF`，如仍有问题，检查：
```bash
ls -la /root/.openclaw/workspace-hotspot/skills/cnki-research-assistant/data/STSONG.TTF
```
