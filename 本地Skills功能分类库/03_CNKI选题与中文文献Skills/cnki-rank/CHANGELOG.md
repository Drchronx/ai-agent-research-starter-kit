# 更新日志

## v1.0 (2026-04-10)

### 新增功能

- ✅ CNKI 接口数据抓取（4 个榜单）
  - 下载热榜（周榜/月榜）
  - 热词榜（周榜/月榜）
- ✅ 数据解析模块
  - JavaScript 转 JSON
  - 字段标准化
- ✅ PostgreSQL 数据持久化
  - 6 张数据表
  - 4 个预置视图
- ✅ 趋势追踪
  - 在榜天数统计
  - 连续周数计算
  - 状态识别（新上榜/持续/回归/下榜）
- ✅ 报告生成
  - Markdown 格式周报/月报
  - 网络搜索分析
  - 飞书文档集成
- ✅ 初始化脚本
  - 交互式数据库配置
  - 自动创建表结构

### 技术细节

- **抓取脚本**：`fetch_cnki.py`
- **解析模块**：`parse_cnki.py`
- **数据库管理**：`db_manager.py`
- **报告生成**：`report_generator.py`
- **初始化**：`init.py`

### 已知问题

1. **排名不连续**：CNKI 接口返回的排名本身不连续（正常现象）
2. **网络搜索限制**：DuckDuckGo API 可能需要代理
3. **抓取限流**：频繁请求会触发 418 错误

### 踩坑记录

1. **SSL 证书验证**：已配置忽略证书验证
2. **JS 解析**：添加键名引号转换
3. **游标类型**：使用 RealDictCursor
4. **网络搜索**：直接调用 DuckDuckGo API
