# Common Method Bias And Measurement Invariance

Use this skill when data are self-report, cross-sectional, multi-group, cross-cultural, or longitudinal.

## Inputs

- Measurement model.
- Data collection procedure.
- Groups for invariance: gender, country, platform, experiment condition, time, or sample source.
- Target journal expectations.

## Workflow

1. Identify common method risk from design: same source, same time, same scale format, social desirability, demand effects.
2. Recommend procedural remedies before data collection.
3. After data collection, choose statistical checks appropriate to the design.
4. For invariance, test configural, metric, scalar, and strict levels only as needed.
5. Interpret partial invariance cautiously.
6. Produce a reviewer-facing measurement-bias statement.

## Hard Constraints

- Do not claim Harman's single-factor test fully solves common method bias.
- Do not use invariance tests when groups are too small without caveats.
- Do not compare latent means without sufficient invariance.
