# Questionnaire Reporting Template

Use this skill to write Methods, Measures, Results, appendix tables, and reviewer responses for questionnaire-based constructs.

## Inputs

- Construct definitions.
- Scale sources and item wording.
- Reliability and validity outputs.
- Factor model outputs.
- Target journal style.

## Workflow

1. Write measurement sources and adaptation steps.
2. Report sample items and response anchors.
3. Report reliability and validity statistics.
4. Report CFA/EFA and measurement model results when available.
5. Report common method bias and invariance checks when relevant.
6. Create appendix materials: full items, source citations, scoring rules.

## Hard Constraints

- Do not cite scale sources that were not verified.
- Do not hide adapted or deleted items.
- Do not claim a scale is validated in the current sample without evidence.
- Keep item wording and anchors exact.

## Output

```text
Measures section:
Measurement table:
CFA/reliability paragraph:
Common method/invariance paragraph:
Appendix item table:
Reviewer-risk checklist:
```
