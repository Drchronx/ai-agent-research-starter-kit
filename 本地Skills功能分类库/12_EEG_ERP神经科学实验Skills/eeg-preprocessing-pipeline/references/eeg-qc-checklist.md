# EEG Quality Control Checklist

Use this checklist for preprocessing and reporting.

## Acquisition

- Sampling rate recorded.
- Montage and reference recorded.
- Impedance threshold recorded.
- Event triggers verified.
- Behavioral log synchronized with EEG events.

## Preprocessing

- Raw data preserved.
- Channel names and locations verified.
- Filters reported with cutoff, order, and direction.
- Bad channels documented.
- Reference choice documented.
- ICA or artifact correction decisions documented.
- Epoch rejection rules predefined.

## Reporting

- Participants excluded and reasons.
- Channels interpolated per participant.
- Trials retained per condition.
- ICA components removed and rationale.
- Final analysis sample and trial counts.
