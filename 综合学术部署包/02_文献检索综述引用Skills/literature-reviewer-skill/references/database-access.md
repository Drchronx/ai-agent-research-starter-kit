# Database Access

Database access is delegated to retrieval skills. Do not implement browser automation in this literature-review skill.

Use `search-backends.md` for backend routing and output normalization.

## Current Backends

- CNKI: use `cnki-crawler`.
- English scholarly search: use an available scholarly-search skill or conservative web search.

When adding a new database, create or select a dedicated backend skill and document its mapping in `search-backends.md`.
