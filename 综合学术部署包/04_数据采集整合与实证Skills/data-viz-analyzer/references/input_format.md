# 输入数据格式规范

## 支持的文件格式

### 1. CSV 文件（.csv）
- 编码：推荐使用 UTF-8，支持 GBK、GB2312、Latin1
- 分隔符：逗号（,）
- 首行：建议包含列名（特征名称）

### 2. Excel 文件（.xlsx, .xls）
- 支持标准 Excel 格式
- 默认读取第一个工作表
- 首行应包含列名

## 数据要求

### 基本要求
- **文件大小**：建议不超过 100MB
- **数据维度**：无严格限制，建议特征数 < 100
- **缺失值**：允许存在，脚本会自动统计和处理

### 数值型特征
- 类型：整数（int）、浮点数（float）
- 用途：
  - 描述性统计分析
  - 相关性分析
  - 分布可视化
- 最少数量：建议至少 2 个数值型特征以进行相关性分析

### 分类特征
- 类型：字符串（object）、类别（category）
- 用途：
  - 唯一值统计
  - 取值分布分析
- 处理方式：自动识别并单独统计

## 数据格式示例

### 示例 1：销售数据（CSV）

```csv
product_id,sales,revenue,profit,region,category
1001,120,15000.50,4500.20,North,Electronics
1002,85,12000.00,3600.00,South,Clothing
1003,200,25000.00,7500.00,East,Electronics
1004,95,8000.00,2400.00,West,Home
...
```

**特征说明**：
- 数值型特征：sales, revenue, profit
- 分类特征：region, category
- 可进行分析：销售趋势、利润分布、相关性分析

### 示例 2：用户行为数据（Excel）

| user_id | age | login_count | purchase_amount | membership_level | registration_date |
|---------|-----|-------------|-----------------|------------------|-------------------|
| U001    | 25  | 156         | 2500.00         | Gold             | 2023-01-15        |
| U002    | 32  | 89          | 1200.50         | Silver           | 2023-02-20        |
| U003    | 28  | 234         | 3800.00         | Platinum         | 2023-03-10        |
| ...     | ... | ...         | ...             | ...              | ...               |

**特征说明**：
- 数值型特征：age, login_count, purchase_amount
- 分类特征：membership_level
- 日期特征：registration_date（会作为字符串处理）

## 数据验证规则

### 自动验证项
1. **文件存在性检查**：验证文件路径是否正确
2. **格式兼容性检查**：验证文件扩展名是否支持
3. **编码兼容性检查**（CSV）：尝试多种编码读取
4. **数据可读性检查**：验证数据能否正确解析

### 常见问题与解决方案

#### 问题 1：编码错误
**现象**：CSV 文件读取失败或中文乱码
**解决**：确保文件使用 UTF-8 编码保存，或使用 Excel 另存为 Unicode 文本格式

#### 问题 2：数值型特征识别失败
**现象**：数值列被识别为分类特征
**解决**：检查数据中是否包含非数值字符（如 "N/A"、"null"、中文描述等）

#### 问题 3：相关性分析无法进行
**现象**：提示"数值型特征少于 2 个"
**解决**：
- 检查数据是否包含数值型列
- 如果数值以字符串形式存储，需在 Excel 中转换为数值格式

#### 问题 4：文件过大导致处理缓慢
**现象**：脚本运行时间过长或内存不足
**解决**：
- 对数据进行采样或分批处理
- 使用 CSV 而非 Excel 格式（读取速度更快）

## 最佳实践建议

### 数据准备
1. **列名规范**：使用有意义的英文列名，避免特殊字符
2. **数据清洗**：提前处理明显的数据质量问题（异常值、格式错误）
3. **类型统一**：确保每列数据类型一致

### 分析优化
1. **特征选择**：保留有分析价值的特征，删除无关列（如 ID、时间戳等）
2. **缺失值处理**：如果缺失值过多（> 50%），考虑删除该特征
3. **样本量控制**：数据量过大时，可先采样分析

## 输出说明

### 生成的文件
- `data_analysis_report.html`：完整的交互式分析报告
- `figures/`：所有可视化图表的 PNG 格式文件

### 报告内容
1. 数据概览（行数、列数、特征类型分布）
2. 缺失值分析（可视化图表 + 统计表）
3. 描述性统计分析（均值、中位数、标准差、分位数等）
4. 特征分布可视化（直方图 + 箱线图）
5. 相关性分析热力图
6. 分类特征统计（唯一值数量、取值分布）

## 注意事项

1. **隐私保护**：分析报告包含数据统计信息，请注意数据隐私
2. **浏览器兼容**：HTML 报告推荐使用 Chrome、Firefox、Edge 等现代浏览器查看
3. **离线查看**：报告为单文件，可直接离线打开，无需网络连接
4. **中文字体支持**：
   - 脚本会自动检测系统中可用的中文字体
   - 支持的字体包括：WenQuanYi Micro Hei（Linux）、Noto Sans CJK（跨平台）、SimHei（Windows）、PingFang SC（Mac）等
   - 如果系统中没有中文字体，图表中的中文可能显示为方块，建议安装开源字体（如 `sudo apt-get install fonts-wqy-microhei`）
