# 第 03 讲：真实文献检索、引用核验与平台联动

副标题：AMiner、AI4Scholar、BibTeX、PDF 下载、AI4Scholar 画图与飞书文献日报

## 一、课程定位

第一讲解决 Agent 基础设施，第二讲解决本地资料如何进入工作流。第三讲解决“真实文献从哪里来、怎么核验、怎么沉淀、怎么每天追踪”的问题。

本讲不是让学生简单学会“搜论文”，而是建立一条可审计的文献生产线：

```text
研究问题 → 检索式 → AI4Scholar/AMiner/OpenAlex 等真实平台 → 元数据核验 → BibTeX → PDF 获取 → 文献日报 → 飞书表格 → 论文卡片/知识库
```

本讲重点：

- AI4Scholar：真实论文检索、详情核验、引用网络、PDF/全文、auto_cite、BibTeX、sci_draw。
- AMiner：学者画像、机构/团队分析、作者同名消歧、专利和知识图谱。
- 飞书表格：每日文献日报、文献筛选表、BibTeX 复核表、PDF 下载状态表。
- 目标期刊 PDF：按期刊、关键词、年份自动搜索并合法下载可获取 PDF 到本地。

建议课时：3-4 小时。

## 二、本讲模板

### 这节课解决什么科研问题和需求

本讲解决 8 类需求：

1. 如何让 AI 找到真实文献，而不是编造引用。
2. 如何生成真实可核验的 BibTeX。
3. 如何复核每条引用是否真的支持句子。

### Agent 应该怎么执行

第三讲采用 10 步执行流：

1. 明确研究主题、关键词、目标期刊、时间范围。
2. 生成 2-4 条英文检索式和 1-2 条中文检索式。
3. 用 AI4Scholar / OpenAlex / PubMed / arXiv / Semantic Scholar 等检索论文。
4. 用 AI4Scholar 批量详情或 `citation-management` 核验 DOI、作者、年份、期刊。
5. 用 AMiner 做学者画像、同名消歧、机构和合作网络分析。
6. 对候选论文生成 BibTeX，并用 `bibtex_audit_template.md` 复核。
7. 按目标期刊和关键词尝试合法下载开放 PDF 到本地。
8. 用 AI4Scholar sci_draw 生成机制图、流程图或图形摘要草图。
9. 生成每日文献日报。
10. 将文献日报同步到本地 Excel 或飞书表格，并更新日志。

### 输出文件应该长什么样

| 输出 | 内容 | 合格标准 |
|---|---|---|
| `literature/search_strategy.md` | 检索式、数据库、时间范围、筛选标准 | 可复现 |
| `literature/candidate_papers.xlsx` | 候选论文表 | 每篇有 DOI/ID/URL 或未核验标注 |
| `literature/verified_references.bib` | 已核验 BibTeX | 不含明显假 DOI 和缺失字段 |
| `literature/bibtex_audit.xlsx` 或 `.md` | BibTeX 复核表 | 句子级支持强度明确 |
| `literature/pdfs/` | 合法下载 PDF | 文件名可追踪，失败有日志 |
| `literature/pdf_download_log.xlsx` | PDF 下载状态 | 记录 access route 和失败原因 |
| `literature/daily_reports/YYYY-MM-DD.md` | 每日文献日报 | 有今日新增、PDF、BibTeX、学者动态 |
| `literature/aminer_scholar_profiles.md` | 学者画像 | 同名消歧证据明确 |
| `figures/sci_draw_prompts.md` | AI4Scholar 画图提示词和版本记录 | 不编造数据图 |
| `feishu/literature_sheet_schema.md` | 飞书字段设计 | 可直接建表 |
| `research_log.md` | 执行日志 | 写明工具、输入、输出、未核验项 |

### 哪些地方必须人工核验

| 风险 | 必须核验 |
|---|---|
| AI 生成引用 | 每条引用是否真实、是否支持对应句子 |
| BibTeX | DOI、题名、作者、年份、期刊、卷期页码 |
| AI4Scholar 检索结果 | 是否是目标主题，是否重复，是否只是相似关键词 |
| AMiner 学者画像 | 中文同名、机构、代表作、合作网络是否匹配 |
| PDF 下载 | 是否合法获取、是否为目标论文、是否完整 |
| 文献日报 | 是否把未核验论文写成已确认 |
| AI4Scholar 画图 | 图中不能出现虚构实验结果、脑区激活、统计数字 |
| 飞书表格 | 是否包含密钥、隐私数据或未经授权 PDF 链接 |

## 三、平台功能侧重

### 1. AI4Scholar 适合什么

AI4Scholar 更偏论文级工具：

- 多源论文检索。
- 论文详情和 DOI/PMID/arXiv 信息。
- 引用网络：参考文献、被引论文、相关论文。
- PDF/全文：开放 PDF、arXiv、bioRxiv、medRxiv、Semantic Scholar OA、合法 DOI 获取。
- `auto_cite`：为段落插入真实引用，输出参考文献和 BibTeX。
- `sci_draw`：科研机制图、流程图、图形摘要、实验流程图。

适合任务：

```text
我要围绕一个研究问题找真实论文、核验引用、读全文、下载 PDF、生成 BibTeX、做机制图。
```

### 2. AMiner 适合什么

AMiner 更偏学术知识图谱：

- 学者画像。
- 机构和团队分析。
- 作者同名消歧。
- 合作网络。
- 专利和应用成果。
- 专家发现和趋势分析。

适合任务：

```text
我要知道某个学者是谁、属于哪个机构、研究什么、有哪些代表作、合作网络如何。
```

### 3. OpenAlex / Semantic Scholar / PubMed 等适合什么

- OpenAlex：开放学术元数据、趋势和引用信息。
- Semantic Scholar：计算机科学、AI、认知科学文献较强，开放 PDF 链接常有用。
- PubMed：医学、神经科学、心理生理、认知神经相关文献。
- arXiv/bioRxiv/medRxiv：预印本和开放 PDF。
- CNKI：中文文献、C 刊、政策和本土问题。

## 四、真实 BibTeX 生成与复核

### 1. 为什么不能让模型直接编 BibTeX

模型可能生成：

- 不存在的 DOI。
- 错误作者顺序。
- 错误期刊名。
- 缺失卷期页码。
- 标题相似但不是同一篇论文。
- 引用支持的是相近主题而不是当前句子。

### 2. 推荐流程

```text
句子拆分 → 判断哪些主张需要引用 → AI4Scholar auto_cite → 输出引用和 BibTeX → DOI/元数据核验 → 句子级支持核验 → 只保留通过核验的 BibTeX
```

### 3. Prompt 示例

```text
Use AI4Scholar auto_cite to add APA 7th citations to the following Introduction paragraph.
Prioritize real top-journal and recent five-year literature, while preserving necessary classics.
Return the cited text, reference list, BibTeX, and a sentence-level citation-support audit table.
Do not add citations to claims that cannot be supported.
```

### 4. BibTeX 复核字段

| 字段 | 核验点 |
|---|---|
| title | 是否与 DOI 页面一致 |
| author | 作者顺序和拼写 |
| year | 在线优先和正式年份区别 |
| journal/booktitle | 期刊或会议是否真实 |
| volume/number/pages | 是否缺失 |
| doi/url | 是否可访问 |
| support_strength | 是否真正支撑句子 |

## 五、每日文献日报与飞书表格联动

### 1. 每日文献日报解决什么

学生每天不可能手动刷所有平台。文献日报的任务是：

- 追踪关键词。
- 追踪目标期刊。
- 追踪目标学者。
- 追踪机构或团队。
- 标注文献是否值得读。
- 标注 PDF 和 BibTeX 状态。
- 把结果沉淀到飞书表格，方便导师或团队协作。

### 2. 日报字段

核心字段：

```text
report_date, topic, query, source, title, authors, year, venue, DOI, url,
relevance_score, method_tag, theory_tag, pdf_status, pdf_local_path,
bibtex_status, verification_status, manual_check_notes, next_action
```

### 3. 飞书表格写入流程

```text
本地日报 Markdown / Excel
  → 字段清洗
  → lark-cli sheets +create 或 +append
  → 飞书表格筛选/排序/协作
  → 每周文献会
```

示例命令：

```bash
lark-cli sheets +create --title "AI Agent 科研每日文献日报" --headers "report_date,topic,query,source,title,authors,year,venue,DOI,url,relevance_score,pdf_status,bibtex_status,verification_status,next_action"
```

已有表格追加：

```bash
lark-cli sheets +append --spreadsheet-token "<spreadsheet_token>" --sheet-id "<sheet_id>" --values "<json rows>"
```

注意：实际字段和参数以当前 `lark-cli sheets +create --help`、`+append --help` 为准。

## 六、目标期刊 PDF 自动下载

### 1. 合法路径优先级

```text
arXiv / bioRxiv / medRxiv
→ Semantic Scholar open-access PDF
→ publisher open-access
→ DOI access when institutional access permits
→ unavailable / manual request
```

### 2. 下载任务 Prompt

```text
Use AI4Scholar to search papers from the target journals:
[journal list]
Topic:
[topic]
Time range:
[year-year]

Verify DOI, title, authors, year, and venue.
Download only open-access PDFs or PDFs available through permitted institutional access.
Save PDFs to literature/pdfs/ using {year}_{first_author}_{short_title}.pdf.
Create literature/pdf_download_log.xlsx and literature/pdf_download_failures.md.
Do not use piracy sites or bypass paywalls.
```

### 3. 失败日志必须保留

无法下载不是失败，未记录才是失败。失败日志应写：

- 论文题名。
- DOI/URL。
- 尝试路径。
- 失败原因。
- 下一步：手动下载、图书馆请求、联系作者、忽略。

## 七、AI4Scholar sci_draw 画图

### 1. 适合画什么

- 理论机制图。
- 文献综述框架图。
- 实验流程图。
- EEG/ERP 实验流程。
- BCI 管线图。
- 文本挖掘或机器学习架构图。
- 图形摘要。

### 2. 不适合画什么

- 编造数据结果图。
- 编造脑区激活图。
- 编造统计显著性。
- 把真实数据可视化交给随机图像生成。

真实数据图应先用 Python/R 画，再用 sci_draw 做风格润色或机制图补充。

### 3. Prompt 模板

```text
Use AI4Scholar sci_draw to generate a publication-style scientific figure.
Figure type: mechanism diagram / workflow / BCI pipeline / EEG experiment procedure / graphical abstract
Research topic:
Required elements:
Forbidden elements:
Language:
Style:
Output requirement: PNG / SVG / editable vector preferred
```

## 八、AMiner 学者画像

### 1. 标准输出

```text
Query target:
AMiner evidence:
Cross-check evidence:
Likely identity:
Representative papers:
Patents or applied outputs:
Coauthor/institution network:
Research trend interpretation:
Unverified items:
Next search actions:
```

### 2. 同名消歧原则

不能只看姓名。必须同时核验：

- 中文名和英文名。
- 当前机构。
- 研究领域。
- 代表论文。
- 合作者。
- 个人主页或 ORCID。
- AMiner 与 AI4Scholar/OpenAlex/官网交叉证据。
