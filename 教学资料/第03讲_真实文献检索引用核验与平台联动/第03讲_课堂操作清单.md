- [ ] 已完成第 01 讲 Agent 工作区部署。
- [ ] 已完成第 02 讲至少 3 张论文精读卡片。
- [ ] 准备一个研究主题。
- [ ] 准备 3 篇种子论文题名或 DOI。
- [ ] 准备目标期刊列表。
- [ ] 如要实操 MCP，准备 AI4Scholar API Key 和 AMiner Token。
- [ ] 如要实操飞书，完成 `lark-cli config init` 或组织授权。

## 3. 写 MCP 示例配置

创建：

```text
configs/mcp.example.json
```

内容：

```json
{
  "mcpServers": {
    "ai4scholar": {
      "url": "https://mcp.ai4scholar.net/sse",
      "headers": {
        "Authorization": "Bearer ${AI4SCHOLAR_API_KEY}"
      }
    },
    "aminer": {
      "url": "https://mcp.aminer.cn/sse",
      "headers": {
        "Authorization": "Bearer ${AMINER_MCP_TOKEN}"
      }
    }
  }
}
```

人工检查：

- [ ] 没有真实 Token。
- [ ] 使用环境变量占位。
- [ ] Agent 支持 MCP SSE。
- [ ] 配置后重启 Agent 或网关。

## 4. 生成检索式

提示词：

```text
我的研究主题是：[主题]。
请生成 4 条英文检索式和 2 条中文检索式。
要求覆盖理论、方法、数据和应用场景。
输出到 literature/search_strategy.md。
不要检索前就编造论文。
```

检查：

- [ ] 检索式不只包含泛泛关键词。
- [ ] 有同义词和近义词。
- [ ] 有方法词，如 experiment、EEG、text mining、machine learning。
- [ ] 有时间范围。
- [ ] 有目标期刊或数据库。

## 5. 搜索真实文献

提示词：

```text
请用 AI4Scholar / OpenAlex / Semantic Scholar 等真实来源检索文献。
主题：[主题]
时间范围：[年份]
目标期刊：[期刊列表]
输出 literature/candidate_papers.xlsx。
每篇至少包含 title, authors, year, venue, DOI_or_ID, url, abstract, source, verification_status。
没有 DOI 或稳定 ID 的文献必须标注“需人工核验”。
```

检查：

- [ ] 至少 20 篇候选文献。
- [ ] 每篇有 DOI、PMID、arXiv ID、S2ID 或 URL。
- [ ] 重复文献已去重。
- [ ] 与主题无关的文献已标注低相关。

## 6. 生成真实 BibTeX

提示词：

```text
请对 literature/candidate_papers.xlsx 中筛选出的 10 篇高相关文献生成 BibTeX。
优先使用 DOI 或稳定 ID 查询元数据。
输出 literature/verified_references.bib 和 literature/bibtex_audit.md。
不要凭题名编造 BibTeX。
```

复核：

- [ ] DOI 与题名一致。
- [ ] 作者顺序一致。
- [ ] 年份一致。
- [ ] 期刊名真实。
- [ ] 卷期页码完整。
- [ ] BibTeX key 不重复。

## 7. 用 auto_cite 给段落加引用

提示词：

```text
Use AI4Scholar auto_cite to add APA 7th citations to the following paragraph.
Prioritize real top-journal and recent five-year literature, while preserving necessary classics.
Return cited text, reference list, BibTeX, and a sentence-level citation-support audit table.
Do not add citations to claims that cannot be supported.

[粘贴段落]
```

人工复核：

- [ ] 引用是否支持对应句子。
- [ ] 是否把方法引用用于理论主张。
- [ ] 是否把综述论文当一手证据。
- [ ] 是否需要替换为更强引用。

## 8. 按目标期刊下载 PDF

提示词：

```text
Use AI4Scholar to search papers from the target journals:
[journal list]
Topic:
[topic]
Time range:
[year-year]

Verify DOI, title, authors, year, and venue.
Download only open-access PDFs or PDFs available through permitted institutional access.
Save PDFs to literature/pdfs/ using {year}_{first_author}_{short_title}.pdf.
Create literature/pdf_download_log.xlsx and literature/pdf_download_failures.md.
Do not use piracy sites or bypass paywalls.
```

检查：

- [ ] 只使用合法开放获取或已有权限的 PDF。
- [ ] 文件名可追踪。
- [ ] 失败日志保留。
- [ ] PDF 是否为目标论文，而不是补充材料。

## 9. 生成每日文献日报

使用模板：

```text
daily_literature_report_template.md
```

提示词：

```text
请基于今天的检索结果、PDF 下载状态、BibTeX 核验状态和 AMiner 学者查询结果，生成每日文献日报。
输出 literature/daily_reports/YYYY-MM-DD.md。
不要把未核验论文写成已确认。
```

日报必须包含：

- 今日新增论文。
- 最值得读的 3-5 篇。
- 学者/团队/机构动态。
- PDF 下载状态。
- BibTeX 状态。
- 人工核验项。
- 明日追踪任务。

## 10. 飞书表格联动

使用模板：

```text
feishu_literature_sheet_schema.md
```

本地先生成：

```text
feishu/daily_literature_rows.xlsx
```

飞书创建表格示例：

```bash
lark-cli sheets +create --title "AI Agent 科研每日文献日报" --headers "report_date,topic,query,source,title,authors,year,venue,DOI,url,relevance_score,pdf_status,bibtex_status,verification_status,next_action"
```

追加行示例：

```bash
lark-cli sheets +append --spreadsheet-token "<spreadsheet_token>" --sheet-id "<sheet_id>" --values "<json rows>"
```

检查：

- [ ] 飞书表格不包含 API Key。
- [ ] PDF 本地路径不泄露敏感文件夹。
- [ ] 未核验状态保留。
- [ ] 写入前先测试 1-2 行。

## 11. AMiner 学者画像

提示词：

```text
请用 AMiner MCP 查询学者：[姓名]，[机构]，[研究领域]。
输出 literature/aminer_scholar_profiles.md。
必须包含：
AMiner evidence, cross-check evidence, likely identity, representative papers, patents or applied outputs, coauthor/institution network, unverified items。
如果 MCP 不可用，请生成手动查询计划，不要编造结果。
```

同名消歧：

- [ ] 中文名和英文名。
- [ ] 当前机构。
- [ ] 研究领域。
- [ ] 代表论文。
- [ ] 合作者。
- [ ] ORCID 或个人主页。
