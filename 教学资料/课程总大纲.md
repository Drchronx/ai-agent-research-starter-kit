# AI Agent 科研全功能教学课程总大纲

适用对象：管理学、心理学、神经科学、计算机科学交叉方向的硕博学生与科研助理。

课程目标：让学生从零开始掌握“Agent + Skills + MCP + 文献平台 + 本地知识库 + 论文生产流程”的完整科研工作法。课程按功能区组织，每一讲都要求学生产出可检查的本地文件，而不是只听概念。

本课程默认使用本地 Skills 库：

```text
<本项目路径>\本地Skills功能分类库
```

## 第 01 讲：AI Agent 科研入门与部署

### 这节课解决什么科研问题和需求
- 解决学生不知道该选哪个 Agent、模型、中转站、Skills、MCP 的问题。
- 建立一个可复用的科研 Agent 工作区，后续所有课程都在这个结构上运行。

### 需要哪些 Skills
- `find-skills`
- `skill-creator`
- `ai4scholar-mcp-openclaw-setup`
- `aminer-mcp-research`
- `lark-*` 系列或飞书/IMA 渠道连接 Skill
- `科研项目管理与版本控制` 类 Skills

### 输入材料是什么
- 学生电脑环境、模型账号或中转站账号。
- 本地 Skills 功能分类库。
- 一个空白科研项目文件夹。
- 课程提供的 `AGENTS.md` / `CLAUDE.md` / `MEMORY.md` 模板。

### Agent 应该怎么执行
- 判断任务属于 Codex、Claude Code、OpenClaw 还是 Hermes。
- 选择国内或国外模型，并配置安全的 API Key 读取方式。
- 将必要 Skills 从本地库复制到项目工作区。
- 配置 Ai4Scholar-MCP、AMiner-MCP、飞书/IMA 渠道的最小可用连接。

### 输出文件应该长什么样
- 一个标准科研工作区。
- 一份项目级 `AGENTS.md`。
- 一个 `skills/` 文件夹。
- 一个 `research_log.md`。
- 一份 MCP 配置草稿，所有密钥用环境变量占位。

### 哪些地方必须人工核验
- 模型调用费用、数据合规、API Key 权限。
- 文献检索结果真实性。
- AMiner 作者同名消歧。
- 飞书/IMA 组织权限与隐私边界。

### 学生课后作业
- 完成自己的科研 Agent 工作区部署。
- 用 Ai4Scholar 或 AMiner 完成一次低成本检索测试。
- 提交工作区截图、配置说明和 1 页反思。

## 第 02 讲：核心文档处理与论文精读

### 这节课解决什么科研问题和需求
- 解决 PDF、Word、Excel、PPT、图片扫描件分散混乱，无法被 Agent 统一读取的问题。
- 让学生把论文、表格、课件变成可检索、可复用、可追踪的 Markdown 和结构化数据。

### 需要哪些 Skills
- `pdf`
- `docx`
- `xlsx`
- `pptx`
- `markitdown`
- `nutrient-document-processing`

### 输入材料是什么
- 3 篇 PDF 论文。
- 1 个 Word 手稿。
- 1 个 Excel 数据表。
- 1 个 PPT 课件。

### Agent 应该怎么执行
- 识别文件类型。
- 抽取正文、标题、表格、图注和参考文献。
- 生成论文精读卡片与数据字典。

### 输出文件应该长什么样
- `output/paper_cards/*.md`
- `output/tables/*.xlsx`
- `output/file_inventory.md`

### 哪些地方必须人工核验
- OCR 错字。
- 表格列名和数值。
- 公式、希腊字母、统计符号。
- PDF 中断行导致的语义错误。

### 学生课后作业
- 处理 5 篇自己研究方向论文。
- 每篇输出一张论文卡片和一个可复用启发条目。

## 第 03 讲：真实文献检索、引用核验与 Ai4Scholar / AMiner

### 这节课解决什么科研问题和需求
- 解决文献引用不真实、检索链路不透明、综述材料不可核验的问题。
- 学会把 Ai4Scholar 的论文级能力与 AMiner 的学者/机构/知识图谱能力结合起来。

### 需要哪些 Skills
- `ai4scholar-research`
- `ai4scholar-paper-search`
- `ai4scholar-paper-detail-batch`
- `ai4scholar-citation-network`
- `ai4scholar-auto-citation-bibtex`
- `aminer-mcp-research`
- `citation-management`
- `openalex-database`

### 输入材料是什么
- 一个研究主题。
- 关键词中英文列表。
- 目标期刊或学科方向。
- 至少 3 篇种子文献。

### Agent 应该怎么执行
- 构造检索式。
- 搜索真实论文。
- 批量核验 DOI、作者、期刊、年份。
- 用 AMiner 做学者、团队、机构和趋势补充。
- 输出 BibTeX 和筛选表。

### 输出文件应该长什么样
- `literature/search_strategy.md`
- `literature/screening_table.xlsx`
- `literature/verified_references.bib`
- `literature/citation_network.md`

### 哪些地方必须人工核验
- DOI 是否真实。
- 作者同名问题。
- 期刊级别与学科匹配。
- 不能只看引用量判断质量。

### 学生课后作业
- 围绕自己的选题建立 30 篇真实文献池。
- 标注每篇文献的理论、变量、方法和可复用启发。

## 第 04 讲：Zotero / Obsidian 长期知识库

### 这节课解决什么科研问题和需求
- 解决文献越读越乱、无法长期沉淀的问题。
- 建立 Zotero 文献库、Obsidian 论文卡片、理论-变量-方法矩阵与研究问题知识图谱。

### 需要哪些 Skills
- `pyzotero`
- `zotero-library-sync`
- `obsidian-paper-card`
- `theory-variable-method-matrix`
- `research-question-knowledge-graph`
- `paper-insight-bank`

### 输入材料是什么
- Zotero API Key 或导出的文献库。
- 论文 PDF。
- 研究主题和已有笔记。

### Agent 应该怎么执行
- 同步 Zotero 文献元数据。
- 生成 Obsidian 卡片。
- 建立变量、理论、方法和研究问题矩阵。
- 输出可复用启发库。

### 输出文件应该长什么样
- `knowledge/paper_cards/*.md`
- `knowledge/theory_variable_method_matrix.xlsx`
- `knowledge/research_question_graph.md`
- `knowledge/reusable_insights.md`

### 哪些地方必须人工核验
- Zotero 条目是否重复。
- 引文元数据是否完整。
- 理论解释是否真的服务机制。
- 变量归类是否符合学科语境。

### 学生课后作业
- 导入 20 篇论文，完成 20 张卡片和 1 张理论-变量-方法矩阵。

## 第 05 讲：文献综述、理论建构与研究问题生成

### 这节课解决什么科研问题和需求
- 解决综述只堆文献、没有问题意识、没有机制线索的问题。
- 学会从文献树走向研究缺口、理论机制和可检验假设。

### 需要哪些 Skills
- `literature-review`
- `research-ideation`
- `idea-tournament`
- `hypothesis-generation`
- `scientific-critical-thinking`
- `paper-planning`

### 输入材料是什么
- 第 03 讲筛选出的文献池。
- 第 04 讲的知识库矩阵。
- 研究方向约束。

### Agent 应该怎么执行
- 先建立主题树，再识别冲突、边界和未解释机制。
- 生成多个研究问题。
- 对研究问题进行新颖性、可行性、理论解释力评分。
- 形成假设和研究设计草案。

### 输出文件应该长什么样
- `writing/literature_tree.md`
- `writing/research_gap_map.md`
- `writing/hypotheses.md`
- `writing/proposal_outline.md`

### 哪些地方必须人工核验
- 文献是否被过度概括。
- 理论是否只是贴标签。
- 假设是否可以被数据检验。
- 贡献是否夸大。

### 学生课后作业
- 提交一份 1500 字研究问题说明，包含真实文献、理论逻辑和可检验假设。

## 第 06 讲：CNKI 中文选题与 C 刊迁移

### 这节课解决什么科研问题和需求
- 解决中文研究选题与国际文献脱节的问题。
- 学会从 CNKI 热点、中文政策语境和 SSCI/SCI 前沿之间找到可迁移问题。

### 需要哪些 Skills
- `cnki-research-assistant`
- `cnki-topic-mining`
- `cnki-trend-analysis`
- `ai4scholar-research`
- `academic-research-openalex`

### 输入材料是什么
- 中文关键词。
- 中文核心/ C 刊目标方向。
- 3 个国际英文关键词。

### Agent 应该怎么执行
- 检索中文主题演化。
- 对照英文前沿文献。
- 找到中文问题、国际理论和可验证方法之间的连接点。

### 输出文件应该长什么样
- `topic/cnki_topic_map.md`
- `topic/cn_en_bridge_table.xlsx`
- `topic/c_journal_idea_bank.md`

### 哪些地方必须人工核验
- CNKI 来源合法性。
- 中文政策表述是否准确。
- 不要把中文热点直接包装成国际贡献。

### 学生课后作业
- 选择一个中文议题，写出可投 C 刊与可投 SSCI 的两个版本选题。

## 第 07 讲：情景实验、行为研究与量表开发

### 这节课解决什么科研问题和需求
- 解决学生不会从顶刊实验中学习情景材料、操纵检验、量表选择和结果汇报的问题。
- 覆盖 UTD24、FT50、JCP、JAP、JCR、ISR、JM、ABS4 等场景实验范式。

### 需要哪些 Skills
- `top-journal-scenario-experiment-mining`
- `scenario-experiment-design`
- `manipulation-check-design`
- `scale-selection`
- `translation-backtranslation`
- `efa-cfa-validity`
- `common-method-bias`

### 输入材料是什么
- 研究问题。
- 目标期刊样例论文。
- 变量定义。
- 初始实验情景草稿。

### Agent 应该怎么执行
- 提取顶刊情景结构。
- 设计实验操纵、流程、量表和质量控制题。
- 规划数据分析与结果汇报。

### 输出文件应该长什么样
- `experiment/stimuli.md`
- `experiment/procedure.md`
- `experiment/scales.xlsx`
- `experiment/analysis_plan.md`

### 哪些地方必须人工核验
- 情景是否真实可信。
- 操纵是否只影响目标变量。
- 量表版权与原始来源。
- 伦理审批和被试保护。

### 学生课后作业
- 完成一个 2 组或 2x2 情景实验方案，并设计操纵检验和主要量表。

## 第 08 讲：数据分析、高级统计与因果推断

### 这节课解决什么科研问题和需求
- 解决会跑基础回归但不会机制检验、稳健性检验和因果边界判断的问题。

### 需要哪些 Skills
- `statistical-analysis`
- `advanced-mediation-moderation`
- `sem-cfa-path-analysis`
- `multilevel-model`
- `causal-inference-did-psm-iv-rdd-dml`
- `result-table-generator`

### 输入材料是什么
- 清洗后的问卷或实验数据。
- 变量字典。
- 研究假设。
- 目标期刊结果呈现样例。

### Agent 应该怎么执行
- 检查数据结构和缺失值。
- 选择统计模型。
- 输出分析脚本、模型表和论文解释。
- 标注哪些结果不能说因果。

### 输出文件应该长什么样
- `analysis/analysis_plan.md`
- `analysis/scripts/*.R` 或 `*.py`
- `analysis/results_tables.xlsx`
- `analysis/result_writeup.md`

### 哪些地方必须人工核验
- 模型假设。
- 变量编码。
- 因果识别条件。
- 显著性与效应量解释。

### 学生课后作业
- 用课程数据完成一次中介/调节/稳健性分析，并写出 APA 风格结果段落。

## 第 09 讲：文本挖掘、LLM 标注与变量构造

### 这节课解决什么科研问题和需求
- 解决文本数据无法转化为可解释变量的问题。
- 学会从评论、公告、访谈、社交媒体或论文摘要中构造管理学/心理学变量。

### 需要哪些 Skills
- `text-mining-pipeline`
- `chinese-word-segmentation`
- `topic-modeling`
- `sentiment-analysis`
- `llm-annotation-protocol`
- `annotation-reliability-audit`

### 输入材料是什么
- 原始文本数据。
- 标注准则。
- 理论变量定义。
- 少量人工标注样本。

### Agent 应该怎么执行
- 清洗文本。
- 构造词典、主题、情感或 LLM 标注变量。
- 做一致性和偏差审计。
- 输出可复现脚本。

### 输出文件应该长什么样
- `textmining/data_dictionary.md`
- `textmining/annotation_codebook.md`
- `textmining/features.xlsx`
- `textmining/reliability_report.md`

### 哪些地方必须人工核验
- 标注准则是否清晰。
- LLM 是否引入理论外推。
- 标签是否与研究假设匹配。
- 训练/测试泄漏。

### 学生课后作业
- 构造一个文本变量，并解释它为什么能代表目标理论概念。

## 第 11 讲：BCI 脑电智能建模

### 这节课解决什么科研问题和需求
- 解决脑电机器学习/深度学习中数据泄漏、跨被试泛化差、结果不可复现的问题。

### 需要哪些 Skills
- `bci-dataset-structure`
- `bci-feature-engineering`
- `bci-ml-classification`
- `bci-deep-learning`
- `bci-cross-subject-transfer`
- `bci-leakage-audit`
- `bci-online-decoding`

### 输入材料是什么
- EEG epochs 或连续数据。
- 标签文件。
- 被试划分表。
- 目标任务说明。

### Agent 应该怎么执行
- 设计训练/验证/测试切分。
- 构建特征工程或深度模型。
- 做被试内、跨被试和留一被试评估。

### 输出文件应该长什么样
- `bci/model_plan.md`

## 第 12 讲：论文写作、审稿、自查与期刊排版

### 这节课解决什么科研问题和需求
- 解决论文写作没有结构推进、投稿排版耗时、盲审稿不合规的问题。

### 需要哪些 Skills
- `paper-writing`
- `paper-review`
- `peer-review`
- `paper-rebuttal`
- `venue-templates`
- `期刊论文排版与投稿格式` 类 10 个排版 Skills

### 输入材料是什么
- 研究设计。
- 分析结果。
- 目标期刊指南。
- 手稿草稿。

### Agent 应该怎么执行
- 按论文结构写作。
- 进行反向大纲和审稿人视角自查。

- 输出盲审稿和投稿检查表。

### 输出文件应该长什么样
- `manuscript/main.docx`

### 哪些地方必须人工核验

- 将一段结果和参考文献转换为目标期刊格式，并完成盲审匿名化审计。

## 第 13 讲：科研可视化、PPT、海报与汇报

- 解决图表难看、机制图不清、汇报材料和论文主线不一致的问题。

- `submission-revision-tracker`

### 输入材料是什么
- 一个真实或模拟科研项目。
- 前 13 讲的阶段性产出。
- 项目目标和提交期限。

### Agent 应该怎么执行
- 建立项目仪表盘。
- 串联文献、实验、分析、写作和投稿流程。
- 输出复现说明和最终展示材料。

### 输出文件应该长什么样
- `project_status.md`
- `reproducibility_readme.md`
- `final_package/`
- `final_report.docx`

### 哪些地方必须人工核验
- 数据来源合法性。
- 脚本能否从零复现。
- 结果文件与论文表述是否一致。
- 合作者贡献和署名。

### 学生课后作业
- 提交一个完整科研 Agent 项目包，包含输入、脚本、日志、输出和人工核验表。
