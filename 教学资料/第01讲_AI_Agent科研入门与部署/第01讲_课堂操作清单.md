# 第 01 讲课堂操作清单

用途：学生照着完成本讲最小可用科研 Agent 工作区。

## 0. 环境准备

- [ ] Windows PowerShell 可正常打开。
- [ ] 已安装 Git。
- [ ] 已安装 Node.js 18+。
- [ ] 已安装 Python 3.10+。
- [ ] 至少有一个可用 Agent：Codex / Claude Code / OpenClaw / Hermes。
- [ ] 有一个模型入口：官方账号或中转站账号。
- [ ] 如需接入文献平台，准备 Ai4Scholar API Key 或 AMiner Token。
- [ ] 如需接入飞书/IMA，确认组织权限、Bot/Webhook/API 权限。

检查命令：

```powershell
git --version
node --version
npm --version
python --version
```

## 1. 创建课堂工作区

```powershell
New-Item -ItemType Directory -Force -Path "D:\AI科研训练营\第01讲_我的Agent工作区"
cd "D:\AI科研训练营\第01讲_我的Agent工作区"

New-Item -ItemType Directory -Force -Path skills,input,literature,output,configs,data,docs
New-Item -ItemType Directory -Force -Path data\raw,data\processed
```

## 2. 创建核心 MD 文件

```powershell
New-Item -ItemType File -Force -Path AGENTS.md,CLAUDE.md,SOUL.md,USER.md,MEMORY.md,project_status.md,research_log.md
```

建议内容：

| 文件 | 写什么 | 禁止写什么 |
|---|---|---|
| `AGENTS.md` | 项目规则、学科背景、引用规则、写作风格、安全规则 | API Key、账号密码 |
| `CLAUDE.md` | Claude Code 项目记忆 | 密钥、不可公开数据 |
| `SOUL.md` | Agent 原则、科研伦理、边界 | 虚构事实 |
| `USER.md` | 使用者背景、研究方向、输出偏好 | 私人敏感信息 |
| `MEMORY.md` | 项目进展、已排除方向、可复用经验 | 未授权数据 |

```powershell
Get-ChildItem "D:\AI科研训练营\第01讲_我的Agent工作区\skills" -Directory
```

## 4. 写 MCP 示例配置

创建文件：

```powershell
cd "D:\AI科研训练营\第01讲_我的Agent工作区"
New-Item -ItemType File -Force -Path configs\mcp.example.json
```

写入内容：

```json
{
  "mcpServers": {
    "ai4scholar": {
      "url": "https://mcp.ai4scholar.net/sse",
      "headers": {
        "Authorization": "Bearer ${AI4SCHOLAR_API_KEY}"
      }
    },
    "aminer": {
      "url": "https://mcp.aminer.cn/sse",
      "headers": {
        "Authorization": "Bearer ${AMINER_MCP_TOKEN}"
      }
    }
  }
}
```

人工检查：

- [ ] 文件中没有真实 Token。
- [ ] 使用的是环境变量占位。
- [ ] Agent 客户端支持 SSE MCP。
- [ ] 重启 Agent 或网关后再测试。

## 6. 模型和中转站选择

参考入口：

```text
https://hvoy.ai/model-select
```

选择前检查：

- [ ] 模型是否支持工具调用。
- [ ] 模型是否支持长上下文。
- [ ] 模型是否适合中文/英文。
- [ ] 费用是否可控。
- [ ] 是否允许上传未公开数据。
- [ ] 中转站是否稳定。
- [ ] 是否有日志留存风险。

## 7. 飞书 / IMA 渠道连接检查

飞书：

- [ ] 是否有开发者后台权限。
- [ ] 是否创建应用或 Bot。
- [ ] 是否授权文档、知识库、多维表格、消息、任务所需 scope。
- [ ] 是否使用环境变量保存 App ID / Secret。
- [ ] 是否先用低风险测试文档验证。

IMA 或其他渠道：

- [ ] 是否支持 Webhook、Bot、MCP、插件或 API。
- [ ] 是否能传递文件、链接和上下文。
- [ ] 是否有组织权限限制。
- [ ] 是否能记录 Agent 执行日志。

## 8. 第一次低风险测试

把下面任务交给 Agent：

```text
请检查当前工作区的 skills 文件夹，确认是否有 ai4scholar-mcp-openclaw-setup 和 aminer-mcp-research。
不要读取或输出任何真实 API Key。
根据 configs/mcp.example.json 生成一份 MCP 配置核验表。
如果无法连接 MCP，请不要编造检索结果，只输出下一步排查清单。
```

预期输出：

```text
output/first_agent_test.md
```

内容应包括：

- 已发现的 Skills。
- MCP 配置状态。
- 需要人工补充的 Token。
- 下一步测试命令或提示词。
- 未核验项列表。

## 10. 常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 把所有 Skills 装进根目录 | Agent 行为混乱，项目不可复现 | 按项目复制到 `skills/` |
| 在文档中写真实 API Key | 密钥泄露 | 改用环境变量占位 |
| 未核验就引用论文 | 论文可能出现假引用 | 用 Ai4Scholar/OpenAlex/DOI 核验 |
| AMiner 同名作者直接采用第一条 | 学者画像错配 | 用机构、领域、代表作消歧 |
| 中转站只看价格 | 输出不稳、隐私风险 | 同时看能力、日志、合规、稳定性 |
