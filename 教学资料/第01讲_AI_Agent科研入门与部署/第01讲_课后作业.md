# 第 01 讲课后作业

## 作业目标

完成一个属于自己的科研 Agent 工作区，并证明它能够安全、可复现地执行一次低风险科研任务。

## 提交文件夹命名

```text
姓名_第01讲_Agent科研工作区
```

## 必交内容

### 1. 工作区结构

文件夹至少包含：

```text
姓名_第01讲_Agent科研工作区/
├─ AGENTS.md
├─ CLAUDE.md
├─ SOUL.md
├─ USER.md
├─ MEMORY.md
├─ project_status.md
├─ research_log.md
├─ configs/
│  └─ mcp.example.json
├─ skills/
├─ input/
├─ literature/
├─ output/
└─ data/
   ├─ raw/
   └─ processed/
```

### 2. `AGENTS.md`

必须写明：

- 你的学科方向。
- 你的研究主题。
- 文献引用规则。
- 理论使用规则。
- 写作风格要求。
- 安全规则。

禁止写入：

- API Key。
- 密码。
- 未公开数据原文。
- 他人个人隐私信息。

### 3. 至少复制 2 个 Skills

建议组合：

```text
ai4scholar-mcp-openclaw-setup
aminer-mcp-research
```

如果你的研究主题不是文献/学者检索，也可以选择：

```text
pdf
docx
markitdown
research-project-skeleton
research-logbook
```

### 4. MCP 示例配置

提交 `configs/mcp.example.json`，格式如下：

```json
{
  "mcpServers": {
    "ai4scholar": {
      "url": "https://mcp.ai4scholar.net/sse",
      "headers": {
        "Authorization": "Bearer ${AI4SCHOLAR_API_KEY}"
      }
    },
    "aminer": {
      "url": "https://mcp.aminer.cn/sse",
      "headers": {
        "Authorization": "Bearer ${AMINER_MCP_TOKEN}"
      }
    }
  }
}
```

真实 Token 不要提交。

### 5. 低风险测试记录

从以下两个任务中选一个：

#### 任务 A：Ai4Scholar 测试

```text
请围绕“AI agent scholarly literature review automation”生成一份真实文献检索计划。
如果 Ai4Scholar-MCP 可用，请执行一次低成本检索并输出候选论文表。
如果不可用，请不要编造结果，只输出配置排查清单。
```

输出文件：

```text
output/ai4scholar_test.md
```

#### 任务 B：AMiner 测试

```text
请用 AMiner-MCP 查询一个你熟悉的学者或研究机构。
如果 AMiner-MCP 可用，请输出学者/机构画像。
如果不可用，请不要编造结果，只输出手动查询计划。
```

输出文件：

```text
output/aminer_test.md
```

## 反思题

提交 `output/reflection.md`，回答 4 个问题：

1. 你的研究任务最适合先用 Codex、Claude Code、OpenClaw 还是 Hermes？为什么？
2. 你会优先用国内模型还是国外模型？依据是什么？
3. 你会把 Skills 放在 Agent 根目录还是项目工作区？为什么？
4. 你这次测试中有哪些结果必须人工核验？

## 评分标准

| 项目 | 分值 | 标准 |
|---|---:|---|
| 工作区结构 | 20 | 文件夹清楚，输入/输出/配置/Skills 分离 |
| 记忆文件质量 | 20 | 规则具体，能约束 Agent 行为 |
| Skills 部署 | 15 | 至少 2 个 Skill，放在项目工作区 |
| MCP 配置 | 15 | 使用环境变量占位，无密钥泄露 |
| 测试记录 | 20 | 不编造结果，能区分已核验和未核验 |
| 反思 | 10 | 能结合自己的研究任务做选择 |

## 直接判为不合格的情况

- 提交文件中包含真实 API Key 或密码。
- 文献结果没有核验却写成“已确认”。
- 把同名 AMiner 学者直接当作目标学者。
- 只提交聊天截图，没有本地工作区文件。
- 没有 `research_log.md`。
