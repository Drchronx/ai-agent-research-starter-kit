# 第 07 讲：情景实验、行为研究与量表开发

副标题：从顶刊实验范式到可执行的 2 组 / 2×2 情景实验方案

## 一、课程定位

第 05 讲解决“研究问题和理论机制”，第 06 讲解决“中文选题和国际迁移”。第 07 讲进入行为研究设计层面，解决：

```text
如何把一个研究问题转化为可操纵、可测量、可预测试、可分析、可报告的情景实验。
```

本讲覆盖管理学、心理学、营销、信息系统、人机交互、神经营销等方向常见情景实验范式，重点参考 JCP、JCR、JM、JMR、ISR、MISQ、JAP、OBHDP、JPSP、Psychological Science、UTD24、FT50、AJG/ABS4 等目标期刊常见做法。

注意：期刊名单和等级会变化，不在课堂中凭记忆断言某期刊属于某榜单。涉及榜单时必须核验年份和来源。

## 二、本讲模板

### 这节课解决什么科研问题和需求

本讲解决 10 类问题：

1. 研究假设写出来了，但不知道如何实验操纵。
2. 情景材料像作文，不能形成干净的因果对比。
3. 操纵同时改变多个构念，导致混淆。
4. 不知道如何设计操纵检验、现实感检验、注意力检验和混淆检验。
5. 不知道如何从 JCP、JCR、JM、JAP、ISR 等顶刊学习实验结构。
6. 量表来源不清楚，存在版权、翻译、回译和适配问题。
7. 把翻译量表误当成已验证量表。
8. 不知道如何规划预测试、主实验、样本量、排除规则和分析模型。
9. 不知道如何做信度、效度、EFA、CFA、共同方法偏差和测量不变性。
10. 不知道如何按顶刊风格报告 Method、Results、Appendix。

### Agent 应该怎么执行

本讲采用 12 步执行流：

1. 创建实验工作区。
2. 复制情景实验、量表、统计和报告 Skills。
3. 写 `AGENTS.md`，限定真实文献、真实量表、伦理和因果语言。
4. 从第 05/06 讲输出中提取因果结构。
5. 用真实顶刊论文建立 benchmark matrix。
6. 选择实验类型：2 组、2×2、中介、调节、选择实验或多研究包。
7. 写情景材料和条件差异表。
8. 设计操纵检验、现实感检验、注意力检验、混淆检验和怀疑检验。
9. 选择量表、设计翻译回译和题项适配。
10. 规划预测试、主实验、样本量、排除规则和伦理材料。
11. 规划数据分析：随机化、操纵检验、信度、主效应、中介、调节、稳健性。
12. 输出 Method/Results 报告模板和审稿风险审计。

### 哪些地方必须人工核验

| 风险 | 人工核验 |
|---|---|
| 顶刊样例论文 | 题名、作者、期刊、年份、DOI、实验是否真实存在 |
| 情景材料 | 是否真实可信，是否符合目标被试经验 |
| 操纵 | 是否只影响目标构念，是否引入能力、风险、成本、情绪等混淆 |
| 操纵检验 | 是否测到操纵构念，而不是中介或因变量 |
| 量表来源 | 题项、锚点、版权、引用和使用语境 |
| 翻译回译 | 翻译不等于验证，必须有预测试和信效度检查 |
| 伦理 | 是否有欺骗、风险、隐私、退出权和知情同意 |
| 样本量 | 是否有 power rationale，不凭感觉定样本 |
| 因果语言 | 场景实验只能支持被操纵变量对结果的因果解释，机制仍需谨慎 |

## 三、核心概念

### 1. 情景实验不是问卷包装

弱设计：

```text
让被试看一个 AI Agent 的介绍，然后问信任、满意度、使用意愿。
```

问题：

- 没有明确操纵。
- 不知道哪一部分导致结果变化。
- 操纵可能同时改变透明度、能力、风险、亲和力和新颖性。

较好设计：

```text
随机分配到高解释透明度 vs 低解释透明度情景。两组材料保持任务、角色、成本、结果、系统能力一致，只改变 AI Agent 是否解释推荐依据。测量不确定性感知、信任和采纳意愿。
```

### 2. 操纵必须服务理论机制

操纵不是让条件“看起来不同”，而是让理论构念发生变化。

```text
理论构念：解释透明度
操纵方式：是否呈现推荐理由、证据来源、判断逻辑和不确定性说明
操纵检验：参与者是否感知到系统解释了推荐依据
混淆检验：系统能力、友好度、任务难度、隐私风险是否没有显著差异
```

### 3. 量表选择不是找几个题项

合格量表表格必须包括：

- 构念定义。
- 量表来源。
- 原始题项。
- 中文翻译。
- 回译计划。
- 锚点。
- 是否反向题。
- 适配修改说明。
- 版权或使用限制。
- 预测试和信效度计划。

### 4. 预测试不是形式

预测试至少回答：

- 操纵是否有效。
- 情景是否真实。
- 条件是否存在混淆。
- 题项是否清楚。
- 完成时间是否合理。
- 是否出现天花板/地板效应。

### 5. 结果报告必须可审计

顶刊式实验报告至少包括：

- 设计和条件。
- 样本、排除和最终 N。
- 随机分配。
- 情景材料。
- 操纵检验。
- 信度。
- 主效应。
- 中介/调节。
- 效应量和置信区间。
- 稳健性和限制。
