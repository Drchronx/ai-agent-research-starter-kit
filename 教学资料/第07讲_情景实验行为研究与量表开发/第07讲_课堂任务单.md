## 任务 3：因果结构

发给 Agent：

```text
请读取 input/lesson05_outputs 和 input/initial_experiment_idea.md，生成 experiment/causal_model.md。
提取研究问题、IV、DV、中介、调节、竞争解释、目标被试、单位随机化和理论机制。
```

- [ ] DV 能被测量。
- [ ] 中介不是操纵检验重复。
- [ ] 有竞争解释。

## 任务 4：顶刊 benchmark

发给 Agent：

```text
请基于 input/target_journal_examples 中的真实论文，生成 experiment/benchmark_matrix.xlsx 的内容草稿。
提取论文信息、实验类型、操纵、样本、检查项、分析模型、报告风格和可复用设计经验。
无法核验的字段写 not verified。
```

检查：

- [ ] 每篇论文真实可查。
- [ ] 确实包含情景实验。
- [ ] 没有编造 DOI、N、结果。

## 任务 5：写情景材料

发给 Agent：

```text
请基于 experiment/causal_model.md，生成 experiment/stimuli.md。
写出所有条件材料；各条件长度一致；角色、任务、背景、风险、成本、结果和语气一致；只改变目标操纵；标注操纵句对应构念。
```

检查：

- [ ] 条件只改变目标操纵。
- [ ] 没有能力、风险、成本、隐私等混淆。
- [ ] 不直接暴露假设。

## 任务 6：条件差异表

填写：

```text
experiment/condition_difference_table.xlsx
```

检查：

- [ ] 每个操纵句都标注构念。
- [ ] 每个潜在混淆有控制方式。
- [ ] 条件长度和语气接近。

## 任务 7：检查项

发给 Agent：

```text
请基于 experiment/stimuli.md，生成 experiment/checks_and_attention.md。
设计操纵检验、现实感检验、清晰度检验、注意力检验、混淆检验、怀疑检验和排除规则。
操纵检验不要与中介或因变量措辞高度重叠。
```

检查：

- [ ] 有操纵检验。
- [ ] 有现实感和清晰度。
- [ ] 有混淆检验。
- [ ] 排除规则提前确定。

## 任务 8：量表

发给 Agent：

```text
请基于 experiment/causal_model.md，生成 experiment/scales.xlsx 的内容草稿。
每个构念包括定义、量表来源、原始题项、翻译题项、锚点、反向题、适配说明、版权说明、既有信度、预测试计划和测量风险。
不要编造量表来源或信度。
```

检查：

- [ ] 量表来源真实。
- [ ] 有原始题项和锚点。
- [ ] 翻译回译有计划。
- [ ] 不把翻译当成验证。

## 任务 9：预测试与主实验

发给 Agent：

```text
请生成 experiment/pretest_plan.md 和 experiment/procedure.md。
预测试包括操纵、现实感、清晰度、混淆、修改规则和进入主实验标准。
主实验包括招募、知情同意、随机分配、流程、排除规则、伦理和数据保存。
```

检查：

- [ ] 有预测试判据。
- [ ] 有主实验流程。
- [ ] 有伦理说明。

## 任务 10：分析计划和审计

发给 Agent：

```text
请生成 analysis/analysis_plan.md 和 qc/experiment_design_audit.md。
分析计划包括数据审计、排除、随机化、操纵检验、信度、主模型、中介/调节、效应量、稳健性和因果语言边界。
审计检查情景真实、操纵混淆、量表来源、预测试、排除规则、伦理和报告风险。
```

检查：

- [ ] 分析模型匹配设计。
- [ ] 有效应量。
- [ ] 有因果语言边界。
- [ ] 审计报告列出致命问题和修改项。
