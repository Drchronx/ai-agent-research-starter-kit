# 第 07 讲教师带做讲稿

本讲定位：把学生的研究问题转成可执行、可预测试、可分析、可报告的情景实验。

授课原则：

- 不让学生把问卷包装成实验。
- 每个操纵必须对应理论构念。
- 情景条件只改变目标操纵。
- 量表来源必须真实可核验。
- 先预测试，再主实验。

## 0. 开场 5 分钟

教师说明：

```text
今天不是教大家写一段情景材料，而是教大家建立一个完整实验系统：操纵、检查、量表、预测试、主实验、分析和报告。
```

板书：

```text
研究问题 → 因果结构 → 顶刊 benchmark → 情景材料 → 检查项 → 量表 → 预测试 → 主实验 → 分析 → 报告
```

强调：

- 情景实验的价值在于干净操纵。
- 情景实验的风险也在操纵不干净。

## 1. 工作区和 Skills 15 分钟

演示创建工作区和复制 Skills。

解释 Skills：

| Skill | 教师解释 |
|---|---|
| `scenario-experiment-benchmark-mining` | 从真实顶刊论文抽取实验设计模式 |
| `scenario-experiment-design` | 把研究问题转成情景实验 |
| `scenario-experiment-analysis` | 规划数据分析 |
| `scenario-experiment-reporting` | 写 Method/Results 和附录 |
| `scale-selection-adaptation` | 找真实量表和翻译适配 |
| `efa-cfa-measurement-model` | 检查测量模型 |
| `common-method-bias-invariance` | 共同方法偏差和测量不变性 |

## 2. 因果结构 20 分钟

教师讲解：

```text
实验不是从情景材料开始，而是从因果结构开始。你必须先说清楚操纵什么、测量什么、为什么会发生、什么是替代解释。
```

现场提问：

- 你的自变量是什么？
- 它能被操纵吗？
- 中介是什么？
- 中介和操纵检验是否重复？
- 因变量是意愿、判断、选择还是行为？
- 谁是目标被试？

## 3. 顶刊 benchmark 35 分钟

教师说明：

```text
不要凭想象设计实验。先从真实顶刊论文中抽取别人如何操纵、如何检查、如何报告。
```

要求学生提供 3-5 篇真实论文。

教师提醒：

- 不要编造论文。
- 不是所有顶刊论文都有情景实验。
- 如果附录不可得，标注 not verified。

## 4. 实验类型选择 20 分钟

讲解：

| 类型 | 适合什么 |
|---|---|
| 两组设计 | 一个清晰因果对比 |
| 2×2 | 一个操纵加一个边界条件 |
| 中介实验 | 机制是核心 |
| 调节中介 | 机制和边界都有强理论 |
| 选择实验 | 因变量是选择或偏好 |

教师强调：

```text
不是越复杂越好。最简洁、最能检验理论的设计才是优先选择。
```

## 5. 情景材料 35 分钟

教师讲解情景材料要求：

- 条件长度接近。
- 角色、任务、背景、风险、成本、结果一致。
- 只改变目标操纵。
- 不暴露假设。
- 语言符合目标被试经验。

示范：

```text
高解释透明度：AI Agent 给出推荐理由、证据来源、匹配逻辑和不确定性说明。
低解释透明度：AI Agent 只给出推荐列表，不说明理由。
```

教师追问：

- 这是否同时改变了系统能力？
- 是否同时改变了友好度？
- 是否改变了风险或隐私感知？

## 6. 检查项设计 25 分钟

教师说明：

```text
操纵检验不是补救工具。操纵不干净时，检验显著也救不了设计。
```

检查项：

- 操纵检验。
- 现实感检验。
- 清晰度检验。
- 注意力检验。
- 混淆检验。
- 怀疑检验。

重点：

- 操纵检验不能和中介/DV 题项高度相同。
- 混淆检验要覆盖能力、风险、成本、友好度、任务难度、隐私。

## 7. 量表选择与适配 30 分钟

教师说明：

```text
量表不是“找几个看起来像的题”。必须有真实来源、构念匹配、翻译回译和预测试。
```

量表表格必须包括：

- 构念定义。
- 量表来源。
- 原始题项。
- 中文翻译。
- 锚点。
- 反向题。
- 适配说明。
- 版权说明。
- 既有信度。
- 预测试计划。

教师提醒：

- 不编造 scale source。
- 不把翻译等同于验证。
- 不因 alpha 不好就随意删题。

## 8. 预测试和主实验 30 分钟

教师讲解预测试目的：

- 操纵是否有效。
- 情景是否真实。
- 是否有混淆。
- 题项是否清楚。
- 是否存在天花板/地板效应。

主实验必须写：

- 招募平台。
- 目标被试。
- 随机分配。
- 知情同意。
- 排除规则。
- 数据匿名化。
- 伦理说明。

## 9. 分析和报告 25 分钟

教师讲解分析顺序：

```text
数据审计 → 排除 → 随机化 → 操纵检验 → 信度 → 主效应 → 中介/调节 → 效应量 → 稳健性 → 报告
```

强调：

- 先定义排除规则，再看结果。
- 报告效应量和置信区间，不只报 p 值。
- 不能把情景实验结果夸大成真实现场行为。

## 10. 收尾 5 分钟

教师总结：

```text
一个好的情景实验，不是情景写得漂亮，而是操纵干净、检查充分、量表可靠、分析透明、报告可审计。
```

课后要求：

- 完成完整实验包。
- 做一次严格审计。
- 写 300 字说明最大混淆风险和控制办法。
