# 第 08 讲：数据分析、高级统计与因果推断

副标题：从变量字典到机制检验、因果识别、结果表和论文解释

## 一、课程定位

第 07 讲完成实验和量表设计，第 08 讲进入数据分析。目标不是“会跑回归”，而是让学生知道：

```text
什么模型适合什么问题，什么结果能支持什么结论，哪些话不能说成因果。
```

本讲覆盖问卷、情景实验、面板数据、二手数据、文本变量和多层/纵向数据的分析规划，重点训练：

- 基础统计和模型选择。
- PROCESS 风格中介、调节、调节中介。
- SEM / CFA / path analysis / latent variable model。
- multilevel / longitudinal / panel model。
- DID、event study、PSM、IV、RDD、DML。
- 结果表生成和论文解释。
- 因果语言边界审计。

## 二、本讲模板

### 这节课解决什么科研问题和需求

本讲解决 10 类问题：

1. 会跑回归，但不知道模型是否匹配研究问题。
2. 会做中介/调节，但不知道因果语言是否成立。
3. 不知道何时用 PROCESS、SEM、CFA、path model。
4. 不知道嵌套、重复测量、纵向数据为什么不能普通 OLS。
5. 不知道 DID、PSM、IV、RDD、DML 分别适合什么数据。
6. 把稳健性检验误当成因果识别。
7. 控制了不该控制的 post-treatment variable 或 collider。
8. 结果显著但效应量很小，不知道怎么解释。
9. 只报 p 值，不报效应量、置信区间和模型诊断。
10. 不知道如何把模型输出写成 APA / 管理学期刊风格结果段落。

10. 生成结果表模板和图形计划。
11. 写结果解释段落。
12. 审计哪些结论可以说因果，哪些只能说关联。

| 风险 | 人工核验 |

## 三、核心概念

### 1. 模型不是越高级越好

弱做法：

```text
我想做 SEM，因为看起来高级。
```

正确问题：

```text
我的构念是否是潜变量？
是否需要同时估计测量模型和结构路径？
普通回归是否已经足够回答问题？
样本量是否支持 SEM？
```

### 2. 机制检验不等于因果机制

PROCESS 中介可以检验间接效应，但如果 X、M、Y 都来自同一时间点自陈问卷，不能直接说“X 导致 M，M 导致 Y”。

更谨慎写法：

```text
结果提供了与理论机制一致的间接效应证据。
```

### 3. 稳健性不是识别

加入控制变量、换模型、换样本、winsorize 都是稳健性，不等于解决内生性。因果识别需要清楚说明：

- 处理变量如何产生。
- 对照组为什么可比。
- 未观测混淆如何处理。
- 识别假设是否可被诊断或部分检验。

### 4. 坏控制比少控制更危险

不要在估计总效应时控制 post-treatment mediator。不要控制 collider。控制变量不是越多越好。

### 5. 结果报告要解释效应量

不合格写法：

```text
X 对 Y 的影响显著，p < .05。
```

更好写法：

```text
X 与 Y 显著正相关（b = 0.24, SE = 0.08, p = .003, 95% CI [0.08, 0.40]）。在控制变量保持不变时，X 增加 1 个单位与 Y 增加 0.24 个单位相关。该结果支持 H1，但由于数据为横截面自陈问卷，不能单独支持因果解释。
```
