## 任务 3：变量字典

发给 Agent：

```text
请读取 input/clean_data，生成 analysis/variable_dictionary.xlsx 的内容草稿。
字段包括 variable_name、variable_label、type、role、coding_or_anchor、source、expected_range、reverse_code、missing_rule、transformation、analysis_use、notes。
不要改变原始数据。无法判断写待人工核验。
```

检查：

- [ ] 反向题标注正确。
- [ ] 条件和处理组编码正确。
- [ ] 时间和 ID 变量清楚。
- [ ] 缺失值规则清楚。

## 任务 4：数据审计

发给 Agent：

```text
请基于 input/clean_data 和 analysis/variable_dictionary.xlsx，生成 analysis/data_audit.md。
检查样本量、变量数量、缺失、重复、异常、范围、条件分布、时间结构、嵌套结构和不能直接分析的问题。
不要删除数据，只报告问题和建议。
```

## 任务 5：假设到模型映射

发给 Agent：

```text
请读取 hypothesis_set.md、variable_dictionary.xlsx 和 data_audit.md，生成 analysis/hypothesis_model_map.xlsx。
每个假设列出 X、Y、M、W、controls、design_type、recommended_model、model_reason、causal_language_allowed、required_diagnostics 和 output_table。
```

## 任务 6：模型选择

发给 Agent：

```text
请基于 hypothesis_model_map.xlsx 和 data_audit.md，生成 analysis/model_selection.md。
判断每个假设适合 t-test/ANOVA、OLS/logistic、PROCESS、SEM/CFA、multilevel、DID/event study、PSM、IV、RDD、DML 中哪一种，并说明理由、数据结构、核心假设、诊断和替代方案。
```

## 任务 7：因果识别审计

发给 Agent：

```text
请使用 causal-inference-design-audit，生成 analysis/causal_identification_audit.md。
包括 estimand、treatment、outcome、timing、DAG/confounding audit、bad controls、推荐方法、识别假设、诊断、稳健性、可以说和不能说的因果结论。
```

## 任务 8：分析计划与脚本

发给 Agent：

```text
请生成 analysis/analysis_plan.md 和 analysis/scripts/analysis_template.py。
包括数据读取、审计、缺失、变量构造、描述统计、相关矩阵、主效应、机制/边界、因果模型、稳健性、图表和输出路径。
脚本不能覆盖原始数据。
```

## 任务 9：结果表

发给 Agent：

```text
请使用 statistical-results-tables，生成 analysis/results_tables.xlsx 的表结构。
包括描述统计、相关矩阵、主效应、中介/调节/SEM/多层/因果模型、稳健性和附录表。
表注说明标准误、固定效应、控制变量、N、显著性标记和变量编码。
```

## 任务 10：结果段落和审计

发给 Agent：

```text
请生成 analysis/result_writeup.md 和 qc/statistical_claims_audit.md。
结果段落按假设顺序写，报告系数、SE/CI、p 值、效应量、N 和因果语言边界。
审计模型匹配、变量编码、坏控制、因果过度、稳健性误用、中介/调节理论、SEM/CFA、DID/IV/RDD/DML 假设、效应量和非显著结果。
```
