# 第 08 讲教师带做讲稿

本讲定位：让学生从“会跑模型”转向“知道模型能支持什么结论”。

授课原则：

- 模型选择必须服务研究问题。
- 因果语言必须匹配研究设计。
- 不改数值、不隐藏非显著结果。
- 结果解释必须包含效应量和边界。

## 0. 开场 5 分钟

教师说明：

```text
今天不是教大家多跑几个模型，而是教大家建立一条可审计的分析链：变量字典、数据审计、模型选择、因果审计、结果表和论文解释。
```

板书：

```text
数据 → 变量字典 → 数据审计 → 假设模型映射 → 模型选择 → 因果审计 → 分析计划 → 结果表 → 结果段落
```

## 1. 工作区与 Skills 15 分钟

解释 Skills：

| Skill | 课堂解释 |
|---|---|
| `statistical-analysis` | 基础检验、效应量、APA 报告 |
| `process-mediation-moderation` | 中介、调节、调节中介 |
| `sem-cfa-path-latent` | 潜变量、CFA、SEM、路径模型 |
| `multilevel-longitudinal-modeling` | 嵌套、重复测量、纵向模型 |
| `did-psm-iv-rdd-dml-event-study` | 准实验和因果 ML |
| `causal-inference-design-audit` | 因果识别和坏控制审计 |
| `statistical-results-tables` | 结果表和结果段落 |

## 2. 变量字典 25 分钟

教师说明：

```text
没有变量字典，不允许直接跑模型。变量名、编码、来源、缺失规则和角色不清楚，模型结果没有解释基础。
```

现场检查：

- 反向题是否标注。
- 条件编码是否正确。
- 处理组和对照组是否清楚。
- 时间变量和 ID 是否存在。
- 缺失值是空白、-99 还是 NA。

## 3. 数据审计 20 分钟

教师说明：

```text
数据审计不是清洗数据，而是先报告数据能不能支持你的研究问题。
```

检查：

- 样本量。
- 缺失。
- 重复。
- 极端值。
- 条件分布。
- 面板结构。
- 嵌套结构。

## 4. 假设到模型映射 25 分钟

教师说明：

```text
每个假设必须有模型对应。不能 H1 用回归，H2 临时换 SEM，只因为结果好看。
```

要求学生回答：

- H1 的 X 和 Y 是什么？
- H2 是否有中介？
- H3 是否有调节？
- 数据是实验、横截面、纵向还是面板？
- 这个假设允许说因果吗？

## 5. 模型选择 40 分钟

教师讲解：

| 问题 | 常见模型 |
|---|---|
| 两组均值差异 | t-test / OLS |
| 多组条件 | ANOVA / planned contrasts |
| 连续 DV | OLS |
| 二元 DV | Logistic |
| 机制 | PROCESS / SEM |
| 潜变量 | CFA / SEM |
| 嵌套或重复测量 | multilevel / mixed model |
| 政策或事件冲击 | DID / event study |
| 可观测匹配 | PSM |
| 外生工具 | IV |
| 截点规则 | RDD |
| 高维混淆 | DML，但不能绕过识别逻辑 |

强调：

```text
高级模型不是装饰。模型必须由数据结构和识别逻辑决定。
```

## 6. 因果审计 45 分钟

教师说明：

```text
因果推断先问识别，不先问显著。稳健性检验不能替代识别。
```

课堂重点：

- causal estimand。
- treatment。
- outcome。
- timing。
- confounder。
- mediator。
- collider。
- bad control。
- post-treatment variable。

方法边界：

- DID：平行趋势。
- PSM：可观测混淆下的可比性。
- IV：相关性和排除限制。
- RDD：截点附近局部效应。
- DML：高维控制，不是黑箱因果魔法。

## 7. 分析计划与脚本 25 分钟

教师说明：

```text
分析计划要在跑结果前写。排除规则、主模型、稳健性和图表都应该提前定义。
```

脚本规则：

- 不覆盖原始数据。
- 输出到 analysis/results 或 output。
- 注释变量构造。
- 固定随机种子，如有随机过程。
- 保存日志。

## 8. 结果表与结果段落 30 分钟

教师说明：

```text
结果表不是把软件输出截图贴上去。表格要能让审稿人看清模型顺序、控制变量、固定效应、标准误、N 和解释边界。
```

结果段落必须包括：

- 系数或均值差异。
- SE 或 CI。
- p 值。
- 效应量。
- N。
- 解释。
- 因果边界。

## 9. 常见错误纠正 15 分钟

典型错误：

- 先跑结果，再决定模型。
- 控制变量越多越好。
- PSM 后直接说因果。
- SEM 拟合好就证明理论。
- 只报告显著结果。
- 把稳健性当识别。
- 不报告效应量。

## 10. 收尾 5 分钟

教师总结：

```text
统计分析不是找显著性，而是让数据、模型和结论之间的关系可审计。论文能不能过审，往往取决于你有没有把“能说什么”和“不能说什么”讲清楚。
```
