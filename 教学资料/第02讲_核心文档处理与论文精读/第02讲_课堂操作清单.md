# 第 02 讲课堂操作清单

用途：学生照着完成一次标准科研文档处理与论文精读流程。

## 0. 课前准备

- [ ] 已完成第 01 讲 Agent 工作区部署。
- [ ] 当前电脑可以正常运行 PowerShell。
- [ ] 准备至少 3 篇 PDF 论文。
- [ ] 准备 1 个 Word 文档。
- [ ] 准备 1 个 Excel 表格。
- [ ] 准备 1 个 PPT 课件。
- [ ] 可选：准备 1 张扫描图片或扫描 PDF。

## 1. 建立第二讲工作区

```powershell
New-Item -ItemType Directory -Force -Path "D:\AI科研训练营\第02讲_文档处理工作区"
cd "D:\AI科研训练营\第02讲_文档处理工作区"

New-Item -ItemType Directory -Force -Path skills,input,converted,extracted,paper_cards,reading_matrix,qc,output
New-Item -ItemType Directory -Force -Path input\papers,input\word,input\slides,input\spreadsheets,input\scans
New-Item -ItemType Directory -Force -Path extracted\tables,extracted\figures,extracted\metadata
New-Item -ItemType File -Force -Path AGENTS.md,research_log.md,project_status.md
```

## 2. 放入输入材料

建议放置规则：

```text
input/papers/          PDF 论文
input/word/            Word 文档
input/slides/          PPT 课件
input/spreadsheets/    Excel 或 CSV
input/scans/           扫描件或图片
```

命名建议：

```text
年份_第一作者_关键词.pdf
2024_Zhang_AI_agent_literature_review.pdf
```

不要使用：

```text
新建文档(1).pdf
论文最终最终版.docx
下载.pdf
```


应看到：

```text
pdf

xlsx
pptx
markitdown
```

## 4. 生成文件盘点表

把下面任务交给 Agent：

```text
请扫描 input/ 下所有文件，先不要总结内容。
请生成 reading_matrix/file_inventory.xlsx，字段包括：
file_id, file_name, file_type, source, research_use, need_ocr, has_tables, has_figures, process_status, output_path, verification_notes。
如果无法判断某项，请写“需人工核验”。
```

人工检查：

- [ ] 每个输入文件都有一行。
- [ ] 文件类型判断正确。
- [ ] 是否需要 OCR 已标注。
- [ ] 是否含表格/图已标注。
- [ ] 输出路径没有写错。

## 5. 转换为 Markdown

把下面任务交给 Agent：

```text
请把 input/papers、input/word、input/slides 中的文件转换为 Markdown。
输出到 converted/。
每个 Markdown 文件开头保留：
原始文件名、转换时间、转换工具、人工核验状态。
不要改写原文主张。
```

人工检查：

- [ ] 标题层级是否保留。
- [ ] 摘要是否完整。
- [ ] 表格是否被误拆。
- [ ] 图注是否丢失。
- [ ] 中文是否乱码。
- [ ] 英文单词是否被断行破坏。

## 6. 生成论文精读卡片

先把本讲提供的 `paper_card_template.md` 放到工作区。

提示词：

```text
请基于 converted/ 中的论文 Markdown，按 paper_card_template.md 生成论文精读卡片。
每张卡片输出到 paper_cards/。
每个结论都要保留来源位置或段落线索。
无法确认的内容写“需人工核验”，不要猜。
```

卡片必须包含：

- 基本信息。
- 研究问题。
- 理论机制。
- 核心变量。
- 样本和数据。
- 方法。
- 主要结果。
- 局限。
- 可复用启发。
- 必须核验项。

## 7. 抽取表格

提示词：

```text
请从 input/papers/ 的 PDF 中识别表格。
把可抽取表格输出到 extracted/tables/*.xlsx。
每个表格必须记录：
来源文件、页码、表号、表题、是否跨页、是否需人工核验。
不要自行补全缺失数值。
```

人工检查：

- [ ] 表头是否错位。
- [ ] 合并单元格是否处理正确。
- [ ] 统计显著性星号是否保留。
- [ ] 表注是否保留。
- [ ] 跨页表是否被截断。

## 8. 建立图注索引

提示词：

```text
请从论文中抽取 Figure 和 Table 的标题与注释。
输出 extracted/figures/figure_index.md。
字段包括：source_file, page, figure_or_table_id, caption, related_section, verification_status。
```

人工检查：

- [ ] 图号是否与正文一致。
- [ ] 图注是否完整。
- [ ] 表号和图号没有混淆。
- [ ] 没有把正文句子误判为图注。

## 9. 生成文献阅读矩阵

提示词：

```text
请根据 paper_cards/ 生成 reading_matrix/literature_reading_matrix.xlsx。
每篇论文一行，字段包括：
paper_id, title, authors, year, journal, research_question, theory, variables, method, sample, key_findings, limitations, reusable_insights, verification_status。
```

人工检查：

- [ ] 每篇论文只有一行。
- [ ] 变量字段没有过度概括。
- [ ] 方法字段具体到实验/问卷/回归/EEG/文本挖掘等。
- [ ] 结论没有被写成超出原文的因果主张。

## 10. 生成核验清单

提示词：

```text
请生成 qc/manual_verification_checklist.md。
按文件列出 OCR、表格、公式、统计符号、参考文献、页码、图注、Excel 公式的核验任务。
不要把未核验内容写成已确认。
```

清单至少包含：

- [ ] OCR 错字。
- [ ] PDF 断行。
- [ ] 表格错位。
- [ ] 公式和统计符号。
- [ ] 图注与图号。
- [ ] 参考文献。
- [ ] Excel 公式错误。
- [ ] 数据隐私。

## 13. 常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 直接让 Agent 总结 PDF | 来源不可追踪 | 先做 file_inventory |
| OCR 结果不核验 | 错字进入后续综述 | 对照原文页面 |
| 表格抽取后直接使用 | 行列错位导致数据错 | 对照原表核验 |
| 论文卡片只写摘要 | 后续不能用于综述和选题 | 按理论、变量、方法、结果结构化 |
| 引用信息不核验 | 可能产生假引用 | 下一讲用 Ai4Scholar/OpenAlex/DOI 核验 |
