# 第 02 讲：核心文档处理与论文精读

副标题：把 PDF、Word、Excel、PPT 和扫描材料变成可检索、可核验、可复用的科研资产

## 一、课程定位

第一讲解决“Agent 怎么部署”的问题。第二讲解决“科研资料怎么进入 Agent 工作流”的问题。

科研新手常见误区是直接把一堆 PDF、Word、PPT 拖给 Agent，然后要求“总结一下”。这种做法的问题是：

- 文件来源和版本不可追踪。
- PDF 抽取结果可能断行、漏表、漏公式。
- 扫描件 OCR 可能错字。
- Excel 表格可能有隐藏公式、合并单元格、错位表头。
- PPT 里的图、图注和讲者备注容易丢失。
- 读完以后没有沉淀成论文卡片、变量矩阵或可复用启发。

本讲的目标是让学生掌握一条标准文档处理生产线：

```text
文件盘点 → 类型识别 → 文本/表格/图注抽取 → Markdown 化 → 论文精读卡片 → 人工核验 → 长期沉淀
```

建议课时：3 小时。

## 二、本讲模板

### 这节课解决什么科研问题和需求

本讲解决 6 类科研需求：

1. 把混乱文件变成清晰的文件清单。
2. 把 PDF、DOCX、PPTX、XLSX 转成 Agent 友好的 Markdown 或结构化表格。
3. 从论文中抽取题名、作者、摘要、理论、变量、方法、样本、数据、结果和局限。
4. 从 PDF 中抽取表格和图注，保留页码来源。
5. 把读论文从“看过了”变成可复用的论文卡片。
6. 建立人工核验清单，避免 OCR、表格、公式、引用错误污染后续研究。

### Agent 应该怎么执行

本讲采用 9 步执行流：

1. 建立工作区文件结构。
2. 复制核心文档处理 Skills。
3. 生成 `file_inventory.xlsx`，记录文件名、类型、来源、用途、处理状态。
4. 对每个文件做质量预检：是否扫描件、是否加密、是否有乱码、是否有表格。
5. 将文件转换成 Markdown 或结构化表格。
6. 从论文中抽取元数据、结构、理论、变量、方法、结果、局限。
7. 生成论文精读卡片。
8. 抽取表格、图注和参考文献，并标注页码来源。
9. 生成人工核验清单并更新 `research_log.md`。

推荐 Agent 任务卡：

```markdown
# 今日 Agent 任务：核心文档处理

## 目标
把 input/ 中的论文和课程材料转成可复用的 Markdown、表格和论文卡片。

## 输入
- input/papers/ 下的 PDF 论文
- input/word/ 下的 Word 文档
- input/slides/ 下的 PPT
- input/spreadsheets/ 下的 Excel

## 可用 Skills
- pdf
- docx
- xlsx
- pptx
- markitdown

## 执行要求
- 先生成 file_inventory.xlsx，不要直接总结。
- 所有抽取内容必须记录来源文件和页码或幻灯片编号。
- 表格抽取结果必须保留原始列名，无法识别的单元格标注“需人工核验”。
- 不要改写论文主张，不要补全缺失 DOI。

## 输出
- reading_matrix/file_inventory.xlsx
- converted/*.md
- extracted/tables/*.xlsx
- paper_cards/*.md
- qc/manual_verification_checklist.md
- research_log.md
```

### 输出文件应该长什么样

| 输出文件 | 内容 | 合格标准 |
|---|---|---|
| `reading_matrix/file_inventory.xlsx` | 文件名、类型、来源、状态、是否需 OCR、处理结果路径 | 每个输入文件都有一行 |
| `converted/*.md` | 转换后的 Markdown 文本 | 保留标题层级、页码或段落来源 |
| `extracted/tables/*.xlsx` | PDF/Word/Excel 中抽取或清洗后的表格 | 列名清楚；疑似错位标注 |
| `extracted/figures/figure_index.md` | 图题、图注、页码、图像用途 | 不替代原图；只做索引 |
| `paper_cards/*.md` | 论文精读卡片 | 包含理论、变量、方法、结果、局限和启发 |
| `reading_matrix/literature_reading_matrix.xlsx` | 多篇论文对比矩阵 | 每篇论文一行，可用于综述 |
| `qc/manual_verification_checklist.md` | 人工核验表 | 列出 OCR、表格、公式、引用等风险 |
| `research_log.md` | 执行日志 | 写清输入、工具、输出、未核验项 |

### 哪些地方必须人工核验

文档处理最容易出现“看似正确”的错误。以下内容必须人工核验：

| 风险点 | 人工核验方法 |
|---|---|
| OCR 错字 | 对照原 PDF 页面或图片 |
| PDF 断行 | 检查摘要、理论段落和结果段落是否被错误换行 |
| 表格错位 | 对照原表格行列，检查合并单元格和跨页表 |
| 公式和统计符号 | 检查希腊字母、上下标、p 值、N、t、F、β |
| 图注与图号 | 检查 Figure/Table 编号是否与正文一致 |
| 参考文献 | 不要凭抽取结果直接引用；必须再用 DOI/数据库核验 |
| Excel 公式 | 检查是否有 `#REF!`、`#DIV/0!`、隐藏列、合并单元格 |
| 论文主张 | Agent 只能抽取和概括，不能替作者补充结论 |
| 数据隐私 | 未公开数据不能上传到外部模型或中转站 |

## 三、课堂讲解重点

### 1. 不要一上来就总结

错误做法：

```text
我把这 10 篇 PDF 给你，你帮我总结一下。
```

正确做法：

```text
先盘点文件，识别文件类型和质量，再按论文精读卡片模板抽取结构化信息。
```

原因：

- 文件未盘点，后续无法追踪来源。
- OCR 和表格错误会被 Agent 当成真实内容继续推理。
- 没有统一模板，读完的材料无法进入综述或写作。

### 2. 文件盘点是第一步

`file_inventory.xlsx` 推荐字段：

| 字段 | 说明 |
|---|---|
| file_id | 文件唯一编号 |
| file_name | 原始文件名 |
| file_type | PDF / DOCX / PPTX / XLSX / Image |
| source | 来源，如课程、数据库、导师、自己下载 |
| research_use | 用途，如文献综述、方法学习、数据分析 |
| need_ocr | 是否需要 OCR |
| has_tables | 是否包含表格 |
| has_figures | 是否包含图 |
| process_status | 未处理 / 已转换 / 已抽取 / 已核验 |
| output_path | 输出文件路径 |
| verification_notes | 人工核验备注 |

### 3. Markdown 是 Agent 友好中间格式

把文件转成 Markdown 的好处：

- Token 更省。
- 标题层级更清楚。
- 便于检索、复制、版本管理。
- 可被后续文献综述、写作、知识库 Skills 复用。

但 Markdown 不是最终事实。转换后的内容必须回到原文件核验。

### 4. 论文精读卡片不是摘要

论文卡片必须服务后续科研任务。它不只是“这篇文章讲了什么”，而是回答：

- 这篇文章解决什么问题。
- 它使用了什么理论解释机制。
- 核心变量是什么。
- 数据和方法是否可靠。
- 结果能支持什么，不能支持什么。
- 对我的研究有什么可复用启发。

### 5. 表格抽取要保守

PDF 表格抽取经常出错，尤其是：

- 跨页表。
- 合并单元格。
- 多层表头。
- 统计显著性星号。
- 变量名换行。
- 注释和系数混在一起。

课堂原则：

```text
宁可标注“需人工核验”，不要让 Agent 自动猜表头或补数值。
```

### 6. Word 与 PPT 也要进入科研资产库

Word 适合：

- 论文草稿版本管理。
- 批注和修改意见整理。
- 会议纪要和读书报告。

PPT 适合：

- 课程知识结构抽取。
- 导师汇报思路复盘。
- 方法课件转笔记。
- 生成后续讲义和课堂资料。

### 7. Excel 是结构化输出的核心

只要涉及多篇论文、多张表、多名被试或多项变量，就应该输出 Excel：

- 文献阅读矩阵。
- 表格抽取结果。
- 变量字典。
- 数据清洗记录。
- 人工核验清单。

Excel 文件必须检查公式错误、列名和单位。

提示词：

```text

```

### 实操 6：抽取表格和图注

提示词：

```text

表格输出为 extracted/tables/*.xlsx。

每个条目必须记录来源文件和页码；无法确认页码时标注“需人工核验”。
```

### 实操 7：生成核验清单

提示词：

```text
请生成 qc/manual_verification_checklist.md。
按文件列出 OCR、表格、公式、统计符号、参考文献、页码、图注、Excel 公式的核验任务。
不要把未核验内容写成已确认。
```
