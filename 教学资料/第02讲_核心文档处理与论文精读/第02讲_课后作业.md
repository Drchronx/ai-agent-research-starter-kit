# 第 02 讲课后作业

## 作业目标

完成一次从“混乱文件”到“结构化科研资产”的完整处理流程。重点不是让 Agent 总结多少内容，而是证明你能把文件、抽取结果、论文卡片和人工核验串成可复现流程。

## 提交文件夹命名

```text
姓名_第02讲_文档处理与论文精读
```

## 必交目录结构

```text
姓名_第02讲_文档处理与论文精读/
├─ AGENTS.md
├─ research_log.md
├─ skills/
├─ input/
│  ├─ papers/
│  ├─ word/
│  ├─ slides/
│  ├─ spreadsheets/
│  └─ scans/
├─ converted/
├─ extracted/
│  ├─ tables/
│  ├─ figures/
│  └─ metadata/
├─ paper_cards/
├─ reading_matrix/
├─ qc/
└─ output/
```

## 输入要求

至少放入 5 个输入文件：

| 类型 | 最低数量 | 要求 |
|---|---:|---|
| PDF 论文 | 3 | 至少 1 篇含表格 |
| Word 文档 | 1 | 论文草稿、读书笔记或课程资料均可 |
| Excel / CSV | 1 | 文献表、实验数据或课程名单均可 |
| PPT | 可选但推荐 | 可用于抽取课程结构 |
| 扫描件 | 可选 | 用于 OCR 风险演示 |

## 必交输出

### 1. 文件盘点表

路径：

```text
reading_matrix/file_inventory.xlsx
```

必须包含字段：

```text
file_id
file_name
file_type
source
research_use
need_ocr
has_tables
has_figures
process_status
output_path
verification_notes
```

### 2. Markdown 转换结果

路径：

```text
converted/
```

要求：

- 至少 3 个转换后的 Markdown 文件。
- 每个 Markdown 文件开头写明原始文件名、转换工具、转换时间和人工核验状态。
- 不得改写原文主张。

### 3. 论文精读卡片

路径：

```text
paper_cards/
```

要求：

- 至少 3 张论文卡片。
- 使用本讲 `paper_card_template.md`。
- 每张卡片必须包含理论、变量、方法、结果、局限和可复用启发。
- 无法确认的信息标注“需人工核验”。

### 4. 表格抽取结果

路径：

```text
extracted/tables/
```

要求：

- 至少 1 个 `.xlsx` 表格。
- 表格中保留来源文件、页码、表号、表题。
- 复杂表格可以不完全自动抽取，但必须写清哪些地方需人工核验。

### 5. 图表索引

路径：

```text
extracted/figures/figure_index.md
```

要求：

- 列出论文中的 Figure 和 Table 标题。
- 记录来源文件和页码。
- 标注是否已人工核验。

### 6. 文献阅读矩阵

路径：

```text
reading_matrix/literature_reading_matrix.xlsx
```

每篇论文一行，至少包含：

```text
paper_id
title
authors
year
journal
research_question
theory
variables
method
sample
key_findings
limitations
reusable_insights
verification_status
```

### 7. 人工核验清单

路径：

```text
qc/manual_verification_checklist.md
```

至少包含：

- OCR 错字。
- PDF 断行。
- 表格错位。
- 公式和统计符号。
- 图注与图号。
- 参考文献。
- Excel 公式错误。
- 数据隐私。

### 8. 执行日志

路径：

```text
research_log.md
```

必须记录：

- 输入文件。
- 使用的 Skills。
- 执行步骤。
- 输出路径。
- 失败或未完成项。
- 人工核验结果。

## 反思题

提交：

```text
output/reflection.md
```

回答以下问题：

1. 本次处理中最容易出错的是 PDF、Word、Excel、PPT 还是扫描件？为什么？
2. 你如何判断 Agent 抽取的表格是否可信？
3. 论文卡片中哪些内容不能直接相信，需要回原文核验？
4. 本次输出如何服务你的后续文献综述或论文写作？

## 评分标准

| 项目 | 分值 | 标准 |
|---|---:|---|
| 工作区结构 | 10 | 输入、转换、抽取、卡片、核验目录清楚 |
| 文件盘点表 | 15 | 每个文件有记录，状态和风险标注清楚 |
| Markdown 转换 | 15 | 转换完整，保留来源和核验状态 |
| 论文卡片 | 20 | 结构完整，能服务综述和选题 |
| 表格/图注抽取 | 15 | 有来源、页码、人工核验标注 |
| 核验清单 | 15 | 能指出具体风险，不空泛 |
| 执行日志与反思 | 10 | 过程可追踪，反思具体 |

## 直接判为不合格的情况

- 只提交 Agent 聊天截图，没有本地文件。
- 没有 `file_inventory.xlsx`。
- 没有人工核验清单。
- 把 OCR 或表格抽取结果直接当作已确认事实。
- 论文卡片中编造 DOI、期刊、作者或结论。
- 上传或提交未授权的敏感数据。
