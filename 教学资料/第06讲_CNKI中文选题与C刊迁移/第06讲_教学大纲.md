# 第 06 讲：CNKI 中文选题与 C 刊迁移

副标题：从中文热点到 C 刊选题，再到 SSCI/SCI 可迁移研究问题

## 一、课程定位

第 05 讲已经让学生把真实文献、论文卡片和理论机制压缩成研究问题。第 06 讲解决另一个关键问题：

```text
如何判断一个中文研究议题是否适合 C 刊发表，又能否迁移为 SSCI/SCI 可理解的国际理论问题。
```

本讲反对三种常见做法：

1. 只追中文热点：把政策热词或社会热点直接写成选题。
2. 只搬英文前沿：把 SSCI/SCI 题目机械翻译成中文 C 刊题目。
3. 两套话语割裂：中文文献讲中国情境，英文文献讲国际理论，中间没有机制桥接。

本讲目标是让学生完成一条完整链路：

```text
中文关键词
→ CNKI 热点/趋势/文献地图
→ C 刊问题意识
→ 英文前沿与国际理论
→ 中英文桥接表
→ C 刊版本选题
→ SSCI/SCI 版本选题
→ 迁移风险审计
```

建议课时：4 小时。

## 二、本讲模板

### 这节课解决什么科研问题和需求

本讲解决 8 类问题：

1. 中文选题只跟热点，没有学术问题。
2. C 刊写作只讲政策意义，缺少理论机制。
3. 国际前沿只做翻译，不能进入中国语境。
4. 中文关键词和英文关键词无法对应。
5. CNKI 检索结果多而乱，不知道如何筛选。
6. 不知道如何判断 C 刊选题是否只是口号。
7. 不知道如何把一个中文议题改写成 SSCI/SCI 版本。
8. 不知道哪些地方必须人工核验：CNKI 来源、C 刊方向、政策表述、引用真实性。

### Agent 应该怎么执行

本讲采用 10 步执行流：

1. 创建中文选题工作区。
2. 复制 CNKI、Ai4Scholar、OpenAlex 和引用核验 Skills。
3. 写 `AGENTS.md`，限定不编造 CNKI 结果、不绕过验证码、不非法下载全文。
4. 定义中文关键词、英文关键词和学科边界。
5. 构造 CNKI 检索式并做语法验证。
6. 生成 CNKI 趋势报告、中文主题地图和中文文献筛选表。
7. 从中文文献中提取 C 刊问题意识、常用理论、方法和数据。
8. 用 Ai4Scholar / OpenAlex 查英文前沿和国际理论。
9. 生成中英文桥接表，判断中文议题如何迁移成国际研究问题。
10. 输出 C 刊版本选题、SSCI/SCI 版本选题和迁移风险审计。

### 哪些地方必须人工核验

| 风险 | 人工核验 |
|---|---|
| CNKI 来源合法性 | 不绕过验证码，不批量非法下载全文，尊重机构授权 |
| 检索式 | 字段代码、引号、逻辑符号、年份范围必须正确 |
| 中文政策表述 | 不误引政策，不把口号写成学术结论 |
| C 刊方向 | 目标期刊栏目、近年选题和方法偏好要人工查看 |
| 中文热点 | 热点不等于学术贡献 |
| 英文前沿 | 不能只用中文关键词直译，必须找到国际构念 |
| 引用真实性 | 中文和英文文献都要核验题名、作者、年份和来源 |
| 选题迁移 | C 刊版本和 SSCI/SCI 版本应有不同问题意识和论证重点 |

## 三、核心概念

### 1. 中文热点不是研究问题

中文热点回答：

```text
现在大家在关注什么？
```

研究问题回答：

```text
已有理论或证据无法解释什么？
```

例如：

```text
弱选题：数字经济背景下企业高质量发展研究。
```

问题：

- “数字经济”太大。
- “高质量发展”太大。
- 没有机制。
- 没有变量。
- 没有可检验方法。

可修改为：

```text
数据要素市场化配置如何通过降低跨组织协同不确定性影响企业数字创新绩效？
```

这个版本至少包含：

- 场景：数据要素市场化配置。
- 机制：跨组织协同不确定性。
- 结果：数字创新绩效。
- 方法可能性：企业数据、文本挖掘、问卷或准实验。

### 2. C 刊问题意识与 SSCI/SCI 理论问题不同

| 维度 | C 刊版本 | SSCI/SCI 版本 |
|---|---|---|
| 起点 | 中国实践、制度、政策、治理场景 | 国际理论、普遍机制、跨情境解释 |
| 贡献 | 解释中国情境中的新问题 | 推进理论机制或边界条件 |
| 文献基础 | 中文核心/CSSCI + 必要英文前沿 | SSCI/SCI 顶刊 + 可迁移中国情境 |
| 方法要求 | 越来越重视严谨识别和数据质量 | 强调理论贡献、方法识别和可推广性 |
| 常见风险 | 政策表述多，理论机制弱 | 中国情境被认为只是样本替换 |

### 3. 中英文桥接不是翻译

错误桥接：

```text
新质生产力 = new quality productive forces
```

这只是词汇翻译。学术桥接要问：

```text
这个中文议题在国际文献中对应哪个理论构念、机制、变量或方法问题？
```

例如：

| 中文议题 | 可能国际桥接 |
|---|---|
| 新质生产力 | innovation capability, digital transformation, technology-enabled productivity |
| 数据要素 | data governance, data asset, data sharing, data-driven innovation |
| 数字政府 | e-government, algorithmic governance, public sector digital transformation |
| 平台治理 | platform governance, algorithmic control, ecosystem governance |
| 智能制造 | smart manufacturing, human-AI collaboration, industrial AI |

桥接后还要判断：

- 国际文献是否已经有成熟理论。
- 中国情境是否提供新的机制或边界。
- 数据和方法是否能支撑理论贡献。

### 4. C 刊选题不是政策作文

政策材料可以提供背景，但不能替代学术论证。

合格 C 刊选题需要：

- 现实问题清楚。
- 学术问题明确。
- 理论机制能解释。
- 变量和数据可操作。
- 与目标期刊栏目和近年文章风格匹配。
