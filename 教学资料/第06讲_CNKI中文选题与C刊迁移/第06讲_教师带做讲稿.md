# 第 06 讲教师带做讲稿

本讲定位：帮助学生把中文研究议题、CNKI 结果、C 刊问题意识和英文前沿文献连接起来。

授课原则：

- 不把中文热点等同于学术贡献。
- 不把英文前沿机械翻译成中文题目。
- 不绕过 CNKI 验证或访问限制。
- 每个选题必须能说清：中国语境是什么，国际理论问题是什么，中间机制如何连接。

## 0. 开场 5 分钟

教师说明：

```text
今天不是教大家“怎么抓 CNKI 文献越多越好”，而是教大家如何判断一个中文议题能否成为 C 刊选题，以及能否迁移为 SSCI/SCI 可理解的理论问题。
```

板书链路：

```text
中文关键词 → CNKI 趋势/文献 → 中文主题地图 → 英文前沿 → 中英文桥接 → C 刊版本 → SSCI/SCI 版本
```

强调：

- C 刊不是政策作文。
- SSCI/SCI 不是把中国样本塞进英文模型。
- 桥接的核心是构念、机制和方法，不是翻译。

## 2. 关键词准备 20 分钟

教师要求学生写下：

- 中文主关键词。
- 3-5 个中文近义词。
- 2-3 个排除词。
- 3 个英文直译词。
- 3 个国际构念词。
- 2 个可能理论机制词。

教师点评：

```text
如果你的英文关键词只是中文词的直译，后面一定会失败。国际文献检索要找构念，不是找中文政策词的英文翻译。
```

例子：

```text
中文：数据要素、数据资产、数据资源
直译：data factor, data asset
国际构念：data governance, data sharing, data-driven innovation
机制词：coordination uncertainty, information asymmetry, digital capability
```

## 3. CNKI 检索式 25 分钟

教师说明：

```text
CNKI 检索式的目的不是一次搜全，而是构建可复现的文献池。宽检索看边界，学科检索看相关，排除检索降低噪音。
```

演示：

```text
V1 宽检索：
SU=('数据要素'+'数据资产'+'数据资源')

V2 学科场景：
SU=('数据要素'+'数据资产') and KY=('企业'+'创新'+'治理')

V3 排除无关：
SU=('数据要素'+'数据资产') and KY=('企业'+'创新') not KY=('会计准则')
```

教师提醒：

- 字段代码必须核验。
- 年份不要写进检索式，用参数。
- 检索式要保存到 `topic/cnki_search_strategy.md`。

## 4. CNKI 趋势与自动分析 45 分钟

教师演示 `cnki-trend`：

```powershell
cd "D:\AI科研训练营\第06讲_CNKI中文选题与C刊迁移工作区\skills\cnki-trend"
python -m pip install -r scripts\requirements.txt
python scripts\cnki_keyword_trend_report.py "数据要素" --output-dir "..\..\reports\cnki_trend\数据要素" --print-report
```

解释趋势报告：

- 年度趋势：是否上升或回落。
- 学科分布：是否集中在经济、管理、信息、法学等。
- 期刊分布：是否有 C 刊相关来源。
- 机构/基金：是否有研究共同体和资助信号。
- 当前年份是 year-to-date，不要和完整年份直接比较。

如果触发验证码：

```text
让学生手动处理，或者停止自动化，改用手动导出。不能绕过验证。
```

## 5. 中文文献筛选表 30 分钟

教师说明：

```text
中文文献筛选表不是题录表，而是判断 C 刊选题的证据表。
```

字段必须包括：

- 题名、作者、期刊、年份。
- 来源类型。
- 关键词、摘要。
- 理论、变量、方法、数据。
- 贡献声称、局限。
- 是否适合 C 刊选题参考。
- 核验状态。

教师现场检查：

- 是否只复制了题名，没有方法和理论。
- 是否把普通期刊误当 C 刊。
- 是否有未核验来源。

## 6. 中文主题地图 25 分钟

教师复制提示词：

```text
请基于 topic/cnki_literature_screening.xlsx、reports/cnki_trend 和 reports/cnki_auto，生成 topic/cnki_topic_map.md。
按中文议题概览、年度趋势、学科分布、研究流派、理论方法、C 刊问题意识、中文研究不足、国际迁移可能性组织。
不要逐篇摘要，不要把热点直接写成贡献。
```

教师点评标准：

- 有没有流派。
- 有没有方法。
- 有没有 C 刊问题意识。
- 有没有中文研究不足。
- 有没有国际迁移可能性。

## 7. 英文前沿与中英文桥接 50 分钟

教师说明：

```text
桥接不是翻译。桥接要回答：中文议题在国际文献里对应什么构念、理论和机制。
```

教师让学生填桥接表：

| 中文议题 | 国际构念 | 共同机制 | 中国情境新增了什么 | C 刊版本 | SSCI/SCI 版本 |
|---|---|---|---|---|---|

教师重点追问：

- 这个英文构念是不是国际文献真的在用？
- 中国情境提供的是新机制、新边界，还是只是样本？
- 英文版本有没有理论贡献？

## 8. C 刊选题库 25 分钟

教师复制提示词：

```text
请基于 topic/cnki_topic_map.md 和 topic/cn_en_bridge_table.xlsx，生成 topic/c_journal_idea_bank.md。
生成 5-8 个 C 刊选题候选。每个选题包含中文题目、问题意识、中国情境、学术缺口、理论机制、变量方法、数据来源、目标 C 刊方向、可迁移 SSCI/SCI 版本和审稿风险。
禁止只写宏大题目。
```

教师现场纠错：

- 题目太大。
- 只有政策背景，没有理论机制。
- 变量不可测量。
- 方法无法支撑结论。

## 9. 双版本选题与审计 30 分钟

教师复制提示词：

```text
请基于 topic/c_journal_idea_bank.md，选择最强 2 个选题，生成 topic/c_vs_ssci_topic_versions.md。
每个选题输出 C 刊版本和 SSCI/SCI 版本，并说明差异。两个版本不能只是互相翻译。
```

再复制审计提示词：

```text
请以严格导师和审稿人视角，审计 topic/c_vs_ssci_topic_versions.md，生成 qc/topic_migration_audit.md。
检查中文热点是否被误写成学术贡献、政策材料是否被误写成理论证据、SSCI/SCI 版本是否只是中国样本替换、中英文构念是否真正对应。
```

## 10. 结尾 5 分钟

教师总结：

```text
中文选题能不能发表，取决于它是不是有清楚的问题意识、理论机制和方法路径。
中文议题能不能国际化，取决于它能否推进国际构念、机制或边界，而不是它在中国很热。
```

课后要求：

- 补齐 CNKI 来源核验。
- 补齐英文代表文献。
- 修改双版本选题。
- 写 300 字反思。
