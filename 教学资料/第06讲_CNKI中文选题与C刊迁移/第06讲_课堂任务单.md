## 任务 3：中文关键词与英文关键词

填写：

```text
input/cn_keywords.md
input/en_keywords.md
```

检查：

- [ ] 中文有主关键词。
- [ ] 中文有同义词/近义词。
- [ ] 有排除词。
- [ ] 英文词不是简单直译，至少有国际构念词。

## 任务 4：CNKI 检索策略

输出：

```text
topic/cnki_search_strategy.md
```

至少包含：

- 检索日期。
- 主关键词。
- 3 个检索式版本：宽检索、学科场景检索、排除无关检索。
- 排序策略：PT、CF、DFR、ZH。
- 年份范围。
- 人工核验项。

检查：

- [ ] 字段代码以 Skill 或 CNKI 官方字段表为准。
- [ ] 引号为英文半角。
- [ ] 逻辑运算符前后有空格。
- [ ] 年份通过参数设置，不写入检索式。

## 任务 5：CNKI 趋势分析

运行：

```powershell
cd "D:\AI科研训练营\第06讲_CNKI中文选题与C刊迁移工作区\skills\cnki-trend"
python -m pip install -r scripts\requirements.txt
python scripts\cnki_keyword_trend_report.py "你的关键词" --output-dir "..\..\reports\cnki_trend\你的关键词" --print-report
```

如果失败：

- [ ] 记录网络、Cookie、验证码或权限原因。
- [ ] 不绕过验证码。
- [ ] 使用手动导出的 CNKI 元数据替代。

## 任务 6：中文文献筛选表

填写：

```text
topic/cnki_literature_screening.xlsx
```

检查字段：

- [ ] 题名、作者、期刊、年份。
- [ ] 来源类型。
- [ ] 关键词和摘要。
- [ ] 理论、变量、方法、数据。
- [ ] 贡献声称和局限。
- [ ] 是否适合 C 刊选题参考。
- [ ] 核验状态。

## 任务 7：中文主题地图

发给 Agent：

```text
请基于 topic/cnki_literature_screening.xlsx、reports/cnki_trend 和 reports/cnki_auto，生成 topic/cnki_topic_map.md。
按中文议题概览、年度趋势、学科分布、研究流派、理论方法、C 刊问题意识、中文研究不足、国际迁移可能性组织。
不要逐篇摘要，不要把热点直接写成贡献。
```

检查：

- [ ] 有趋势判断。
- [ ] 有流派和方法。
- [ ] 有 C 刊问题意识。
- [ ] 有中文研究不足。
- [ ] 没有把政策口号写成学术贡献。

## 任务 8：英文前沿检索

发给 Agent：

```text
请基于 input/cn_keywords.md 和 topic/cnki_topic_map.md，生成英文检索词表。
区分直译词、国际构念、理论机制词、方法词和目标领域词。
不要只做中文直译。
```

然后用 Ai4Scholar / OpenAlex 检索英文文献，保存到：

```text
reports/english_frontier/
```

检查：

- [ ] 有国际构念。
- [ ] 有理论机制词。
- [ ] 有代表英文文献。
- [ ] 引用标注已核验或待核验。

## 任务 10：C 刊选题库与双版本选题
