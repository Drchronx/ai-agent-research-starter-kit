本讲目标：让完全没有 EEG/ERP 分析基础的学生，能从研究问题、实验范式、事件码和数据结构开始，建立可复现的 EEG/ERP 分析方案，并知道哪些地方必须人工核验。

## 3. 第三步：写 AGENTS.md

把下面内容写入 `AGENTS.md`：

```markdown
# 第10讲工作区 Agent 指令

你是 EEG/ERP 神经科学实验助手。

原则：
- 禁止覆盖原始 EEG 数据。
- 禁止看到结果后临时更改滤波、时间窗、ROI、trial 剔除或统计模型。
- 禁止把 ERP 成分、频段或连接指标直接等同心理构念。
- 所有事件码、行为数据和 EEG 文件必须能按 subject_id / trial_id 对齐。
- ICA 删除、坏道插值、被试剔除和 trial 剔除必须写理由。
- 机器学习任务必须先做数据泄漏审计。
- 结果报告必须包含 QC、剔除、保留 trial 和解释边界。
```

## 4. 第四步：先写研究问题和神经假设

复制给 Agent：

```text
请基于我的研究主题，生成 eeg/study_design.md。

必须包括：
1. 研究问题。
2. 理论机制。
3. 行为假设。
4. 神经假设。
5. 目标 ERP 成分或频段指标。
6. 实验范式。
7. trial 时序。
8. 事件码设计原则。
9. EEG 记录设置。
10. 预处理和分析路线。
11. 伦理和风险。

注意：不要把 ERP 成分直接等同心理构念。每个神经指标都要说明任务时序和解释边界。
```

示例：

```text
研究主题：AI Agent 推荐解释透明度如何影响用户信任。
可能范式：阅读推荐解释 → 做采纳/拒绝判断 → 反馈。
可能指标：P3 / LPP 表征注意资源或动机相关加工线索；FRN 表征反馈评价线索。
```

## 5. 第五步：设计事件码表

EEG/ERP 最关键的是事件码。至少要能区分：

- 刺激出现。
- 条件类别。
- 被试反应。
- 反馈出现。
- 正确/错误。
- 任务阶段。

复制给 Agent：

```text
请生成 eeg/event_marker_table.xlsx 的内容草稿。

每个事件码必须包含：
- marker_code
- event_name
- condition
- time_locking_role
- trial_phase
- expected_count
- behavior_link
- included_in_erp
- notes

请检查是否存在事件码重复、条件不可区分、无法 time-lock、与行为日志无法对齐的问题。
```

## 8. 第八步：生成预处理计划

复制给 Agent：


## 10. 第十步：ERP 分析计划

复制给 Agent：

```text
请生成 eeg/erp_analysis_plan.md。

必须包括：
1. time-locking event。
2. epoch window。
3. baseline window。
4. artifact rejection rule。
5. condition averaging。
6. ERP component。
7. ROI electrodes。
8. time window。
9. amplitude/latency metric。
10. statistical model。
11. figure plan。
12. exploratory vs confirmatory 标记。

注意：不要看波形后选择最大差异窗口，除非明确标为探索性。
```

常见 ERP 设置示例：

```text
P1：80-130 ms，枕区/顶枕区
N1：100-180 ms，枕区/顶枕区
N2：200-350 ms，额中区
P3：300-600 ms，顶区
N400：300-500 ms，中央-顶区
LPP：400-800 ms 或更晚，中央-顶区
FRN：200-350 ms，额中区
ERN：0-100 ms response-locked，额中区
```

这些只是课堂示例，真实研究必须结合任务和文献。

## 11. 第十一步：频域、时频和连接计划

复制给 Agent：

```text
请生成 eeg/frequency_connectivity_plan.md。

必须包括：
1. 目标频段：theta/alpha/beta/gamma 等。
2. 分析方法：PSD、STFT、wavelet、ERSP、ITC、coherence、PLV、wPLI 等。
3. baseline 和归一化。
4. ROI、时间窗和频段。
5. 多重比较控制。
6. 图表计划。
7. 连接解释边界。

注意：连接指标不是因果方向，频段解释必须和任务时序、理论和文献对应。
```

## 12. 第十二步：EEG 机器学习最小入门

复制给 Agent：

```text
请生成 eeg/eeg_ml_plan.md。

必须包括：
1. prediction target。
2. label 来源。
3. feature 类型：ERP、band power、time-frequency、connectivity、raw epochs。
4. 被试内、跨被试或留一被试验证。
5. train/validation/test 划分。
6. 防泄漏规则。
7. baseline model。
8. deep model 是否必要。
9. metrics：accuracy、balanced accuracy、AUC、F1、confusion matrix、CI。
10. permutation test 或 nested CV，如适用。
11. 解释边界。

注意：预测准确率不是神经机制证据。
```
