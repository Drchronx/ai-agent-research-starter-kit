# 第 10 讲教师带做讲稿

## 开场 0-8 分钟：先把底线讲清

今天这节课不是教大家盲跑 EEG 脚本。脑电研究最容易出现的问题不是软件不会用，而是实验范式、事件码、预处理和分析窗口没有闭环。

教师强调：

```text
EEG/ERP 可信结果 = 设计合理 + 事件码准确 + 预处理透明 + 分析窗口先验 + QC 完整 + 解释克制
```

## 8-18 分钟：展示最终交付物

打开第10讲文件夹，展示：

- `study_design.md`
- `event_marker_table.xlsx`
- `data_structure.md`
- `preprocessing_plan.md`
- `preprocessing_qc.xlsx`
- `erp_analysis_plan.md`
- `erp_component_table.xlsx`
- `frequency_connectivity_plan.md`
- `eeg_ml_plan.md`
- `eeg_results_template.md`
- `qc/eeg_analysis_audit.md`

教师话术：

这套文件是把脑电实验从“个人经验处理”转成“审稿人可复核流程”。学生哪怕现在没有真实 EEG 数据，也要能设计出一条不会把数据做坏的分析链路。

## 18-30 分钟：创建工作区和复制 Skills

带学生执行 PowerShell 命令。

检查：

```powershell
Get-ChildItem
Get-ChildItem .\skills
```

教师提醒：

- Skills 放工作区，不放根目录。
- 原始 EEG 数据放 `data/raw`，不要覆盖。
- 行为数据和事件日志分开保存。
- 所有参数变动写入 `research_log.md`。

## 30-45 分钟：研究问题与神经假设

教师举例：

研究问题：

```text
AI Agent 解释透明度是否影响用户对推荐结果的信任和采纳？
```

可能神经假设：

```text
高解释透明度可能增强与注意资源分配相关的 P3/LPP 线索；
反馈或推荐错误可能诱发 FRN 相关反馈评价线索。
```

教师纠错：

- 不能直接写“P3 = 信任”。
- 不能只因文献里有人用过某成分，就把它套到自己的任务。
- 神经假设必须对应任务时序和 time-locking event。

## 45-60 分钟：事件码设计

教师讲解事件码表：

- `marker_code`
- `event_name`
- `condition`
- `trial_phase`
- `time_locking_role`
- `expected_count`
- `behavior_link`
- `included_in_erp`

现场提问：

1. 哪个事件作为 ERP time-locking？
2. 条件差异是否能从 marker 中区分？
3. 反应和反馈是否也需要 marker？
4. 行为日志中有没有同一个 trial_id？

教师提醒：

事件码错了，后面所有 ERP 平均都可能错。

## 60-78 分钟：预处理计划

教师带学生生成 `preprocessing_plan.md`。

讲解顺序：

```text
raw backup → import → channel/montage → events check → filter → bad channels
→ reference → ICA/artifact → epoch → baseline → rejection → QC
```

教师重点纠错：

- 不能看到效果后换滤波。
- 不能删除 ICA 成分不写理由。
- 不能不同条件用不同剔除标准。
- 不能只报告“我们做了预处理”，必须报告参数和 attrition。

## 78-92 分钟：ERP 分析计划

教师讲解 ERP 表：

- 成分。
- time-locking event。
- epoch window。
- baseline window。
- ROI electrodes。
- time window。
- metric。
- statistical model。
- confirmatory/exploratory。

示例：

```text
P3：stimulus-locked，300-600 ms，Pz/CPz/Cz，mean amplitude，条件内重复测量 ANOVA。
FRN：feedback-locked，200-350 ms，FCz/Cz，mean amplitude，反馈类型 × 条件。
```

教师提醒：

时间窗和 ROI 必须先验或有文献依据。看图选最大差异窗口，只能标为探索性。

## 92-105 分钟：频域、时频和连接

教师讲解：

- alpha 抑制、theta 增强、beta/gamma 变化都必须结合任务和理论。
- ERSP 要说明 baseline。
- 连接指标如 coherence、PLV、wPLI 不是因果方向。
- 多频段、多电极、多时间窗容易产生多重比较问题。

教师现场要求学生写：

```text
frequency_connectivity_plan.md
```

## 105-115 分钟：EEG 机器学习防泄漏

教师讲解：

如果是被试内分类，可以 epoch 随机划分，但解释限于同一被试内。

如果声称跨被试泛化：

```text
训练集和测试集必须按被试隔离。
```

教师纠错：

- 不允许同一被试 epoch 同时进入 train/test，却声称跨被试。
- 不允许在全数据上标准化再划分。
- 不允许只报告一个 accuracy，不报告 chance level 和 CI。

## 115-125 分钟：结果写作和图表

教师展示常见图：

- ERP waveform。
- Scalp topography。
- Trial retention table。
- ERSP time-frequency plot。
- Connectivity matrix。
- Confusion matrix。

教师提醒：

结果图必须和分析计划对应。不能只展示显著窗口、隐藏其他 planned tests。

## 125-135 分钟：审稿人式审计

让学生生成：

```text
qc/eeg_analysis_audit.md
```

教师重点检查：

- 事件码是否完整。
- 预处理是否先验。
- ERP 窗口是否循环选择。
- QC 是否透明。
- 连接和成分解释是否过度。
- 机器学习是否泄漏。

## 收尾

教师总结：

脑电实验的核心不是“跑出一张漂亮波形图”，而是能向审稿人解释：你为什么这么设计、为什么这么清洗、为什么看这个窗口、为什么这个神经指标能支持但不能过度支持你的理论。
