# 第 04 讲学生逐步操作手册

目标：完全照着本手册操作，完成一个 Zotero / Obsidian 长期知识库。

## 第 0 步：你要完成什么

本讲结束后，你的电脑里应该有：

```text
第04讲_知识库工作区/
├─ Zotero 文献导出
├─ Obsidian Vault
├─ 3 张论文卡片
├─ 1 张理论-变量-方法矩阵
├─ 1 个研究问题知识图谱
├─ 1 个可复用启发库
└─ 1 份人工核验清单
```

## 第 1 步：安装 Zotero

1. 打开：

```text
https://www.zotero.org/download/
```

2. 下载 Zotero 桌面端。
3. 安装后打开 Zotero。
4. 创建或登录 Zotero 账号。
5. 安装 Zotero Connector 浏览器插件。
6. 在浏览器中打开任意论文网页，确认右上角出现 Zotero 保存按钮。

人工检查：

- [ ] Zotero 桌面端能打开。
- [ ] 浏览器能看到 Zotero Connector。
- [ ] 保存网页时 Zotero 中能出现新条目。

## 第 2 步：安装 Obsidian

1. 打开：

```text
https://obsidian.md/download
```

2. 下载并安装 Obsidian。
3. 暂时不要创建 Vault，先完成第 4 步工作区结构。

人工检查：

- [ ] Obsidian 能打开。
- [ ] 知道 `Vault` 是一个本地文件夹。
- [ ] 知道 Obsidian 笔记本质是 Markdown 文件。

## 第 3 步：安装推荐插件

### Zotero 推荐插件

推荐安装 Better BibTeX：

- 用途：生成稳定 citation key。
- 用途：自动导出 BibTeX。
- 用途：让 Zotero 与论文写作引用保持一致。

安装后建议：

- 打开 Zotero 设置。
- 找到 Better BibTeX 设置。
- 设置 citekey 格式。

建议 citekey：

```text
auth.lower + year + shorttitle(3,3)
```

示例：

```text
smith2024aitrust
```

### Obsidian 推荐插件

推荐：

- Templates：使用模板。
- Dataview：后续按字段检索论文卡片。
- Obsidian Zotero Integration：从 Zotero 生成笔记。

课堂不强制所有插件都现场配置成功；先完成本地文件夹和 Markdown 卡片。

## 第 6 步：设计 Zotero 分类

在 Zotero 左侧新建 Collection：

```text
00_inbox
01_to_read
02_reading
03_core_theory
04_methods
05_measures
06_datasets

09_daily_literature

```

操作：

1. 右键 `My Library`。
2. 点击 `New Collection`。
3. 逐个创建上面的 Collection。

人工检查：

- [ ] Collection 名称完全一致。
- [ ] 新文献先进入 `00_inbox`。
- [ ] 核心理论文献移动到 `03_core_theory`。

## 第 7 步：导入 10 篇文献

方法 A：浏览器保存

1. 打开论文网页。
2. 点击 Zotero Connector。
3. 确认条目进入 Zotero。
4. 如果有 PDF，确认 PDF 附件是否保存。

方法 B：拖入 PDF

1. 把 PDF 拖入 Zotero。
2. 右键条目。
3. 选择 `Retrieve Metadata for PDF`。
4. 检查元数据是否正确。

方法 C：用 DOI 添加

1. Zotero 顶部点击魔法棒。
2. 输入 DOI。
3. 自动创建条目。

人工检查：

- [ ] 至少 10 篇文献。
- [ ] 至少 5 篇有 PDF。
- [ ] 每篇都有题名、作者、年份、期刊。
- [ ] DOI 缺失的条目标注 `status:needs_check`。

## 第 8 步：给文献打标签

每篇文献至少 3 个标签：

```text
field:...
method:...
status:...
```

示例：

```text
field:management
method:scenario_experiment
status:to_read
```

重要文献加：

```text
role:classic
role:must_read
role:method_source
role:measure_source
role:theory_source
```

人工检查：

- [ ] 没有大量未打标签文献。
- [ ] 标签不要中英文混乱。
- [ ] 同一含义只保留一个标签。

## 第 9 步：导出 Zotero 文献

手动导出：

1. 在 Zotero 中选中一个 Collection。
2. 右键。
3. 选择 `Export Collection`。
4. 格式选择 BibTeX。
5. 保存到：

```text
D:\AI科研训练营\第04讲_知识库工作区\zotero_exports\references.bib
```

如果导出 CSV/JSON，也保存到：

```text
zotero_exports/
```

人工检查：

- [ ] `references.bib` 存在。
- [ ] citekey 不重复。
- [ ] 重要文献 DOI 没丢。

## 第 10 步：配置 Zotero API

如果你要让 Agent 直接读取 Zotero Web API：

1. 打开：

```text
https://www.zotero.org/settings/keys
```

2. 找到 User ID。
3. 创建 API Key。
4. 在本机环境变量或私有 `.env` 中保存。

示例文件：

```text
configs/zotero.env.example
```

内容：

```text
ZOTERO_LIBRARY_ID=your_user_or_group_id
ZOTERO_LIBRARY_TYPE=user
ZOTERO_API_KEY=your_private_key
```

注意：

- 不要把真实 API Key 提交作业。
- 不要发到飞书群。
- 不要写进 Obsidian 公共 vault。

## 第 11 步：审计 Zotero 文献库

把下面任务交给 Agent：

```text
Use zotero-library-sync to audit my Zotero library export.
Do not display API keys.
Use files in zotero_exports/.
Export zotero_items.csv, references.bib, metadata_audit.xlsx, and obsidian_paper_index.md.
Check missing DOI, duplicate titles, missing PDF attachments, untagged items, and inconsistent venue names.
Do not write changes back to Zotero.
```

输出应包括：

```text
zotero_exports/zotero_items.csv
zotero_exports/metadata_audit.xlsx
zotero_exports/obsidian_paper_index.md
```

人工检查：

- [ ] 缺 DOI 条目列出来了。
- [ ] 重复题名列出来了。
- [ ] 缺 PDF 条目列出来了。
- [ ] 未打标签条目列出来了。

## 第 14 步：生成 3 张论文卡片

把下面任务交给 Agent：

```text
Use obsidian-paper-card to create Obsidian notes for three core papers.
Use obsidian_paper_note_template.md.
Each note must include YAML frontmatter, citation, one-sentence takeaway, research question, theory mechanism, variables, method, data/sample, key results, limitations, reusable ideas, and links.
Separate paper evidence from my interpretation.
Output notes to obsidian_vault/01_Papers/.
```

人工检查：

- [ ] 每篇论文一张卡。
- [ ] 文件名格式为 `@FirstAuthorYear_ShortTitle.md`。
- [ ] 有 YAML。
- [ ] 有 Zotero key 或 citation key。
- [ ] 理论不是只写名称。
- [ ] 有人工核验项。

## 第 15 步：建立理论、变量、方法笔记

在 Obsidian 中创建：

```text
obsidian_vault/02_Theories/
obsidian_vault/03_Variables/
obsidian_vault/04_Methods/
```

示例：

```text
02_Theories/Technology_Acceptance.md
03_Variables/Trust_in_AI.md
04_Methods/Scenario_Experiment.md
```

在论文卡片中插入链接：

```text
[[Technology_Acceptance]]
[[Trust_in_AI]]
[[Scenario_Experiment]]
```

人工检查：

- [ ] 点击链接可以跳转。
- [ ] 理论、变量、方法不是都堆在论文卡片里。
- [ ] 每个核心概念有单独页面。

## 第 16 步：生成理论-变量-方法矩阵

把下面任务交给 Agent：

```text
Use theory-variable-method-matrix to build a matrix from my Obsidian paper cards.
Extract theory, mechanism, constructs, variable roles, measurement, method design, sample, analysis model, key result, limitations, and reuse_for_my_project.
Export matrices/theory_variable_method_matrix.xlsx and matrices/theory_variable_method_matrix.md.
Do not treat theories as decorative labels.
```

人工检查：

- [ ] 至少 10 行。
- [ ] 每行有 note_link。
- [ ] theory 和 mechanism 分开写。
- [ ] construct 和 measurement 分开写。
- [ ] verification_status 不为空。

## 第 17 步：生成研究问题知识图谱

把下面任务交给 Agent：

```text
Use research-question-knowledge-graph to build a knowledge graph for my research question.
Use Zotero items and Obsidian paper cards as sources.
Return node tables, typed edges, a Mermaid graph, and gap candidates requiring verification.
Output graphs/research_question_graph.md and graphs/research_question_edges.xlsx.
```

人工检查：

- [ ] 节点有类型。
- [ ] 边有类型。
- [ ] 每条重要边有证据来源。
- [ ] gap candidates 标注需要进一步检索。

## 第 18 步：建立可复用启发库

把下面任务交给 Agent：

```text
Use paper-reusable-insight-bank to extract reusable insights from the three paper cards and the matrix.
Separate reusable theory, variables, methods, experiment designs, EEG/ERP/BCI ideas, text-mining ideas, and writing/rebuttal ideas.
Output reusable_insights/paper_reusable_insight_bank.md.
```

人工检查：

- [ ] 启发是具体的，不是“值得学习”。
- [ ] 每条启发能追溯到论文。
- [ ] 区分理论、变量、方法、写作。

## 第 19 步：建立每日维护流程

每天 20-40 分钟：

1. 新文献进 Zotero `00_inbox`。
2. 补 DOI、作者、年份、期刊、PDF。
3. 打标签。
4. 核心文献生成 Obsidian 卡片。
5. 更新矩阵。
6. 更新知识图谱。
7. 写入可复用启发库。
8. 更新 `research_log.md`。
