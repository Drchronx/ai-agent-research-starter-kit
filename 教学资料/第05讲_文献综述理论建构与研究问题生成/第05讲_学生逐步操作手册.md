# 第 05 讲学生逐步操作手册

目标：从前几讲的真实文献、论文卡片和知识库出发，生成文献树、研究缺口、理论机制链、假设组和一页研究方案。

## 第 0 步：你要完成什么

本讲结束后，你应该有：

```text
第05讲_综述与选题工作区/
├─ review/literature_tree.md
├─ review/research_gap_candidates.md
├─ review/research_gap_audit.md
├─ review/synthesis_outline.md
├─ theory/theory_mechanism_chain.md
├─ hypotheses/hypothesis_set.md
├─ proposal/one_page_research_proposal.md
├─ qc/gap_and_theory_audit.md
└─ research_log.md
```

## 第 4 步：明确研究方向

在 `research_log.md` 写：

```markdown
## 第05讲研究方向

### 我的研究方向

### 长期目标

### 目标学科/期刊

### 可用方法
- 情景实验
- EEG/ERP
- 文本挖掘
- 机器学习/深度学习
- 因果推断

### 本讲希望生成的问题
```

要求：

- 方向不能太大。
- 不能只写“AI agent”。
- 要写清研究对象、情境、机制或方法。

## 第 5 步：生成文献树

把下面任务交给 Agent：

```text
Use research-ideation and literature-review to build a literature tree from my paper cards and theory-variable-method matrix.
Create both:
1. Novelty Tree
2. Challenge-Insight Tree
Output review/literature_tree.md.
Do not summarize papers one by one.
Organize by problems, mechanisms, variables, methods, and unresolved challenges.
```

人工检查：

- [ ] 文献树不是按年份排列。
- [ ] 文献树不是逐篇摘要。
- [ ] Novelty Tree 有贡献类型。
- [ ] Challenge-Insight Tree 有挑战和已有解决方式。
- [ ] 每个分支有代表文献。

## 第 6 步：识别研究流派和争议

把下面任务交给 Agent：

```text
Based on review/literature_tree.md, identify major research streams and controversies.
For each stream, list core question, theory, variables, methods, representative papers, and limitations.
For each controversy, explain whether the conflict comes from theory, sample, method, measurement, or context.
Append the result to review/literature_tree.md.
```

人工检查：

- [ ] 每个流派有核心问题。
- [ ] 每个争议有具体来源。
- [ ] 不把所有差异都写成“研究视角不同”。

## 第 7 步：生成研究缺口候选池

把下面任务交给 Agent：

```text
Based on review/literature_tree.md and input/matrices/theory_variable_method_matrix.xlsx, generate 5-8 candidate research gaps.
For each gap, state:
gap type, supporting papers, what is known, what remains unknown, why it matters, and what evidence is still missing.
Output review/research_gap_candidates.md.
```

人工检查：

- [ ] 每个 gap 有类型。
- [ ] 每个 gap 有真实文献证据。
- [ ] 每个 gap 写了仍需核验的内容。
- [ ] 没有“已有研究很少”这种空话。

## 第 8 步：缺口审计

把下面任务交给 Agent：

```text
Use research_gap_audit_template.md to audit each candidate gap.
For each gap, perform a well-established solution check:
Has existing literature already solved it?
Is it merely a new context/sample?
Does it require new theory, new mechanism, new measurement, or new method?
Output review/research_gap_audit.md.
```

人工检查：

- [ ] 对每个 gap 做了反证搜索。
- [ ] 已经被解决的 gap 被放弃或修改。
- [ ] 只换样本/情境的 gap 没有被夸大。
- [ ] 保留的 gap 能说明为什么重要。

## 第 9 步：生成综述提纲

把下面任务交给 Agent：

```text
Create a literature review synthesis outline.
Do not organize by year or by individual paper.
Organize by:
1. core problem,
2. theoretical explanations,
3. mechanisms and variables,
4. methods and evidence,
5. unresolved gaps,
6. my study's position.
Output review/synthesis_outline.md.
```

人工检查：

- [ ] 提纲有问题推进。
- [ ] 不是按作者/年份堆材料。
- [ ] 综述最后能自然推出自己的研究。

## 第 10 步：选择最强研究缺口

建立一个简单评分表：

| gap_id | importance | novelty | feasibility | theory_value | method_fit | total | decision |
|---|---:|---:|---:|---:|---:|---:|---|
| G1 |  |  |  |  |  |  | keep/revise/drop |

评分标准：

- importance：是否重要。
- novelty：是否真有新意。
- feasibility：是否能做。
- theory_value：是否有理论价值。
- method_fit：是否适合你的方法能力。

保留 1 个最强 gap，最多保留 1 个备选 gap。

## 第 11 步：建立理论机制链

把下面任务交给 Agent：

```text
Use theory_mechanism_chain_template.md to build a theory mechanism chain for the strongest research gap.
Connect:
context/stimulus/technology change → psychological/cognitive mechanism → behavioral/attitudinal/performance outcome.
Separate constructs from measured variables.
Output theory/theory_mechanism_chain.md.
```

人工检查：

- [ ] 理论解释了机制。
- [ ] 构念和变量分开。
- [ ] 每个变量有测量或操纵方式。
- [ ] 不存在理论和变量错位。

## 第 12 步：生成假设组

把下面任务交给 Agent：

```text
Use hypothesis-generation and hypothesis_set_template.md to create a testable hypothesis set.
Include main effect, mediation, moderation, and conditional indirect effect only if theoretically justified.
For each hypothesis, include mechanism explanation, literature support, measurement/design, analysis method, and causal language warning.
Output hypotheses/hypothesis_set.md.
```

人工检查：

- [ ] 不为了复杂而硬加中介/调节。
- [ ] 每个假设都有理论机制。
- [ ] 每个假设有数据或实验设计可以检验。
- [ ] 没有把相关写成因果。

## 第 13 步：生成一页研究方案

把下面任务交给 Agent：

```text
Use one_page_research_proposal_template.md to write a one-page research proposal.
The proposal must include:
title, research question, importance, literature gap, theory mechanism, research model, hypotheses, design, expected contribution, risks, and next steps.
Output proposal/one_page_research_proposal.md.
```

人工检查：

- [ ] 3 分钟内能读懂。
- [ ] 研究问题清楚。
- [ ] 缺口不是空话。
- [ ] 理论机制能支撑假设。
- [ ] 方法可执行。
- [ ] 贡献没有夸大。

## 第 14 步：导师前审计

把下面任务交给 Agent：

```text
Use scientific-critical-thinking to audit my one-page research proposal.
Check:
theory fit, gap validity, variable-measure alignment, method fit, causal language, contribution overclaim, feasibility, and target journal fit.
Output qc/gap_and_theory_audit.md.
```

人工检查：

- [ ] 审计报告指出具体问题。
- [ ] 不是只说“整体不错”。
- [ ] 每个问题有修改建议。
