# 第 05 讲教师带做讲稿

本讲定位：把学生前四讲积累的文献、论文卡片、Zotero/Obsidian 知识库，转化为可讨论的研究问题、理论机制和假设。

授课原则：

- 先让学生产出结构化文件，再讨论写作。
- 不允许直接让 Agent 写一篇完整综述。
- 每一步都要求学生人工核验。
- 对明显站不住的缺口要当场指出。

## 0. 开场 5 分钟

教师说明：

```text
今天不是学“怎么让 AI 写综述”，而是学“怎么让 Agent 帮你把文献变成问题结构”。
如果没有结构，AI 写得越流畅，越容易掩盖你的选题问题。
```

板书链路：

```text
论文卡片 → 证据表 → 文献树 → 流派与争议 → 缺口候选 → 缺口审计 → 理论机制链 → 假设 → 一页方案
```

提醒学生：

- 本讲不追求语言漂亮。
- 本讲追求问题是否清楚、缺口是否成立、理论是否解释机制。

## 1. 工作区与 Skills 15 分钟

教师演示：

```powershell
New-Item -ItemType Directory -Force -Path "D:\AI科研训练营\第05讲_综述理论与选题工作区"
cd "D:\AI科研训练营\第05讲_综述理论与选题工作区"
New-Item -ItemType Directory -Force -Path input,review,theory,hypotheses,proposal,figures,qc,output,skills
New-Item -ItemType Directory -Force -Path input\paper_cards,input\matrices,input\graphs,input\bibliography
New-Item -ItemType File -Force -Path AGENTS.md,research_log.md
```

教师强调：

```text
Skills 放在工作区，不放根目录。这样每个项目需要什么就复制什么，不污染全局环境。
```

建议解释每类 Skill：

| Skill 类型 | 课堂解释 |
|---|---|
| 文献综述 Skill | 帮你组织证据，不是帮你编文献 |
| 引用核验 Skill | 查 DOI、BibTeX、题名、作者、年份 |
| 理论矩阵 Skill | 把理论、变量、方法对齐 |
| 假设生成 Skill | 把机制转成可检验假设 |
| 批判审计 Skill | 模拟导师或审稿人挑问题 |

## 2. 输入材料检查 20 分钟

教师让学生打开自己的 `input` 文件夹。

逐项检查：

- 是否有文献池。
- 是否有已核验 BibTeX。
- 是否有论文卡片。
- 是否有理论-变量-方法矩阵。
- 是否有研究问题图谱。

教师提示：

```text
如果你今天材料不完整，可以跟着做流程，但不要把课堂输出当作真实选题。没有真实文献支撑的部分必须标注“待核验”。
```

课堂提问：

- 你的研究对象是谁？
- 你的场景是什么？
- 你的核心机制可能是什么？
- 你的结果变量是什么？
- 你准备用什么方法检验？

## 3. 生成证据表 25 分钟

教师讲解：

```text
证据表是防止 AI 胡写的第一道防线。先把文献中的问题、理论、变量、方法和局限拉成表，再决定怎么综述。
```

教师复制提示词：

```text
请读取 input/paper_cards、input/candidate_papers.xlsx 和 input/matrices 中的材料，生成 review/evidence_table.md。

不要写综述正文。每篇文献提取 citation_key、研究问题、理论、变量、机制、方法、发现、局限和可复用启发。
没有依据的字段写“未提供”，不要猜。
如果引用真实性无法确认，标注“待核验”。
```

教师现场检查 1-2 个学生输出：

```text
这一列写“理论”，但实际只是变量名，不是理论。
这一篇没有 citation_key，必须回到 BibTeX 或平台核验。
这个“局限”写得太泛，要写具体不能解释什么。
```

## 4. 生成文献树 35 分钟

教师说明：

```text
文献树的作用是看清领域结构。一个好的综述不是“谁说了什么”，而是“领域围绕什么问题形成了哪些解释和争议”。
```

展示两棵树：

```text
Novelty Tree：已有研究贡献了哪些新理论、新变量、新方法、新情境。
Challenge-Insight Tree：领域面对哪些挑战，已有研究如何处理，哪里仍未解决。
```

教师复制提示词：

```text
基于 review/evidence_table.md，生成 review/literature_tree.md。
建立 Novelty Tree 和 Challenge-Insight Tree。
不要按年份排列，不要逐篇摘要。
每个分支列代表文献、已有解释、未解决问题和对我选题的启发。
```

教师点评要点：

- 如果学生输出按年份排列，要求重跑。
- 如果每个分支没有代表文献，要求补。
- 如果只写主题，不写挑战，说明文献树不合格。

## 5. 流派与争议 25 分钟

教师说明：

```text
研究流派让你知道别人从哪些路线解释问题。争议让你知道哪里可能有缺口。
但不是所有不一致都能变成缺口。
```

教师复制提示词：

```text
基于 review/evidence_table.md 和 review/literature_tree.md，生成 review/research_streams_and_controversies.md。
列出 3-5 个主要研究流派和 2-4 个主要争议。
每个争议说明来源：理论、样本、测量、方法、数据或情境。
```

教师强调：

- 争议来源要具体。
- 不要把“研究视角不同”当万能解释。
- 争议能否转化为缺口，要看是否能提出新的机制或检验方式。

## 6. 生成并审计缺口 60 分钟

教师讲解好缺口：

```text
好缺口不是“研究少”，而是“现有解释在某个机制、情境、测量或方法上不能回答关键问题”。
```

教师展示弱缺口：

```text
已有研究较少关注 AI Agent 对科研效率的影响。
```

教师改写：

```text
已有研究虽讨论 AI 建议采纳和自动化信任，但在科研文献筛选这类高不确定、高专业判断任务中，解释透明度是否通过降低不确定性感知影响采纳，仍需要结合具体任务行为进行检验。
```

教师复制生成缺口提示词：

```text
基于文献树、流派争议和证据表，生成 5-8 个研究缺口候选。
每个缺口包含：类型、已知内容、未知内容、重要性、支持证据、可能研究问题、可行方法、审稿风险、补充检索需求。
禁止空话。
```

教师复制审计提示词：

```text
请严格审计 review/research_gap_candidates.md，输出 review/research_gap_audit.md。
对每个 gap 判断：是否已被解决、是否只是换情境、需要的新贡献、可行性、审稿风险、最终决策 keep/revise/drop。
不要迎合我，弱 gap 必须指出。
```

课堂互动：

- 让学生把最强 gap 读出来。
- 教师问：已有研究真的没做吗？
- 教师问：这个 gap 是理论缺口、机制缺口，还是只是换情境？
- 教师问：你准备用什么数据检验？

## 7. 理论机制链 30 分钟

教师说明：

```text
理论不是写在引言里的装饰。理论要回答为什么 X 会影响 Y，以及在什么条件下更强或更弱。
```

教师复制提示词：

```text
基于最强研究问题，生成 theory/theory_mechanism_chain.md。
请区分情境/刺激、理论、构念、变量、测量、机制和结果。
说明理论为什么适配，也说明理论不能解释的边界。
```

教师检查：

- 理论核心命题是否写出来。
- 构念是否能测量。
- 机制是否能用实验、问卷、EEG/ERP、文本挖掘或行为数据检验。
- 是否有理论边界。

## 8. 假设组 20 分钟

教师说明：

```text
假设不是“X 正向影响 Y”。假设是理论预测，必须说明为什么、如何检验、能不能支持因果语言。
```

教师复制提示词：

```text
基于 theory/theory_mechanism_chain.md，生成 hypotheses/hypothesis_set.md。
每个假设包括：假设文本、机制解释、文献支持、测量/操纵、分析方法、因果语言风险。
只写理论必要的中介和调节。
```

教师重点纠错：

- 没有机制的主效应。
- 没有理论依据的中介。
- 没有边界逻辑的调节。
- 用横截面数据写因果。

## 9. 一页方案与导师前审计 25 分钟

教师说明：

```text
一页方案的目标不是完整，而是让导师快速判断方向是否值得投入。
```

教师复制提示词：

```text
请基于前面所有输出，生成 proposal/one_page_research_proposal.md。
必须包括：题目、研究问题、重要性、文献缺口、理论机制、研究模型、假设、设计、数据与分析、贡献、风险、下一步计划。
```

再复制审计提示词：

```text
请以严格审稿人和导师视角，审计 proposal/one_page_research_proposal.md，生成 qc/gap_and_theory_audit.md。
检查缺口、理论、变量、方法、因果语言、引用真实性和贡献夸大。
```

教师让学生最后提交：

- 一页研究方案。
- 审计报告。
- 课堂反思。

## 10. 结尾 5 分钟

教师总结：

```text
今天真正重要的不是生成了多少文字，而是你有没有把模糊想法压缩成可检验问题。
下一讲如果进入中文文献或 CNKI 选题，就要继续验证这个问题在中文语境和 C 刊话语体系中是否成立。
```

课后要求：

- 补足真实文献核验。
- 修改被审计指出的问题。
- 用 300 字说明自己的原始想法被哪里修正了。
