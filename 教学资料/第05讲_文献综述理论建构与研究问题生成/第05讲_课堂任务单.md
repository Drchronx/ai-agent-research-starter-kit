## 任务 1：建立工作区

运行：

```powershell
New-Item -ItemType Directory -Force -Path "D:\AI科研训练营\第05讲_综述理论与选题工作区"
cd "D:\AI科研训练营\第05讲_综述理论与选题工作区"

New-Item -ItemType Directory -Force -Path input,review,theory,hypotheses,proposal,figures,qc,output,skills
New-Item -ItemType Directory -Force -Path input\paper_cards,input\matrices,input\graphs,input\bibliography
New-Item -ItemType File -Force -Path AGENTS.md,research_log.md
```

检查：

- [ ] 工作区能打开。
- [ ] 有 `input`、`review`、`theory`、`hypotheses`、`proposal`、`qc` 文件夹。
- [ ] 有 `AGENTS.md` 和 `research_log.md`。

## 任务 2：复制 Skills

运行：

```powershell
cd "<本项目路径>\本地Skills功能分类库"

powershell -ExecutionPolicy Bypass -File .\00_工具脚本\copy_skill_to_workspace.ps1 `
  -SkillName literature-review,ssci-literature-review,ai4scholar-research,ai4scholar-citation-network,citation-management,hypothesis-generation,scientific-critical-thinking,research-proposal,theory-variable-method-matrix,research-question-knowledge-graph `
  -Workspace "D:\AI科研训练营\第05讲_综述理论与选题工作区"
```

检查：

- [ ] `skills/` 中至少有文献综述、引用核验、假设生成、批判审计相关 Skills。
- [ ] 没有把 Skills 安装到 Codex 根目录。
- [ ] 缺失 Skill 已记录在 `research_log.md`。

## 任务 3：准备输入材料

复制：

```text
input/candidate_papers.xlsx
input/bibliography/verified_references.bib
input/paper_cards/*.md
input/matrices/theory_variable_method_matrix.xlsx
input/graphs/research_question_graph.md
```

检查：

- [ ] 文献池至少 20 篇。
- [ ] 论文卡片至少 5 张。
- [ ] BibTeX 至少 10 条已核验。
- [ ] 没有明显编造文献。

## 任务 4：生成证据表

发给 Agent：

```text
请读取 input/paper_cards、input/candidate_papers.xlsx 和 input/matrices 中的材料，生成 review/evidence_table.md。
不要写综述正文。每篇文献提取 citation_key、研究问题、理论、变量、机制、方法、发现、局限和可复用启发。
没有依据的字段写“未提供”，不要猜。
```

检查：

- [ ] 有 `review/evidence_table.md`。
- [ ] 每行能追溯到真实材料。
- [ ] 没有凭空出现的新文献。

## 任务 5：生成文献树

发给 Agent：

```text
基于 review/evidence_table.md，生成 review/literature_tree.md。
建立 Novelty Tree 和 Challenge-Insight Tree。
不要按年份排列，不要逐篇摘要。
每个分支列代表文献、已有解释、未解决问题和对我选题的启发。
```

检查：

- [ ] 有 Novelty Tree。
- [ ] 有 Challenge-Insight Tree。
- [ ] 每个分支有代表文献或待核验标记。

## 任务 6：生成研究流派与争议

发给 Agent：

```text
基于 review/evidence_table.md 和 review/literature_tree.md，生成 review/research_streams_and_controversies.md。
请列出 3-5 个研究流派和 2-4 个主要争议。
每个争议说明来源：理论、样本、测量、方法、数据或情境。
```

检查：

- [ ] 每个流派有核心问题和常用方法。
- [ ] 每个争议有具体来源。
- [ ] 没有把所有争议都写成“视角不同”。

## 任务 7：生成缺口候选池

发给 Agent：

```text
基于文献树、流派争议和证据表，生成 5-8 个研究缺口候选，输出 review/research_gap_candidates.md。
每个缺口包含：类型、已知内容、未知内容、重要性、支持证据、可能研究问题、可行方法、审稿风险、补充检索需求。
禁止空话。
```

检查：

- [ ] 每个 gap 有类型。
- [ ] 每个 gap 有已知/未知。
- [ ] 每个 gap 有真实文献或待核验文献支撑。
- [ ] 至少有 1 个 gap 被标注为高风险。

## 任务 8：缺口审计

发给 Agent：

```text
请严格审计 review/research_gap_candidates.md，输出 review/research_gap_audit.md。
对每个 gap 判断：是否已被解决、是否只是换情境、需要的新贡献、可行性、审稿风险、最终决策 keep/revise/drop。
不要迎合我，弱 gap 必须指出。
```

检查：

- [ ] 至少 1 个 gap 被 drop 或 revise。
- [ ] 保留 gap 有明确理由。
- [ ] 每个保留 gap 有反证检索建议。

## 任务 9：理论机制链

发给 Agent：

```text
基于最强研究问题，生成 theory/theory_mechanism_chain.md。
请区分情境/刺激、理论、构念、变量、测量、机制和结果。
说明理论为什么适配，也说明理论不能解释的边界。
```

检查：

- [ ] 理论不是只写名称。
- [ ] 每个变量能被测量或操纵。
- [ ] 机制链能读成“为什么 X 会影响 Y”。

## 任务 10：假设组

发给 Agent：

```text
基于 theory/theory_mechanism_chain.md，生成 hypotheses/hypothesis_set.md。
每个假设包括：假设文本、机制解释、文献支持、测量/操纵、分析方法、因果语言风险。
只写理论必要的中介和调节。
```

检查：

- [ ] 假设不是变量关系口号。
- [ ] 每个假设都有检验方式。
- [ ] 没有滥用因果语言。

## 任务 11：一页研究方案与审计

发给 Agent：

```text
请生成 proposal/one_page_research_proposal.md。
然后以严格导师视角生成 qc/gap_and_theory_audit.md。
```

检查：

- [ ] 一页方案包含题目、问题、缺口、理论机制、假设、设计、贡献、风险。
- [ ] 审计报告列出致命问题、重要问题、可修改问题和下一步行动。

姓名_第05讲_综述理论与研究问题生成/
