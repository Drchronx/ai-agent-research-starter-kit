# 研究缺口审计模板

用途：判断一个“研究缺口”是否真的成立，避免把“我没看到”“我想做”误写成学术缺口。

## 1. 缺口候选

```text
gap_id:
gap_statement:
source:
```

## 2. 缺口类型

| 类型 | 是否属于 | 说明 |
|---|---|---|
| 理论缺口 | yes/no | 现有理论不能解释某机制 |
| 机制缺口 | yes/no | 变量关系存在，但中间过程不清楚 |
| 边界条件缺口 | yes/no | 关系在什么条件下成立不清楚 |
| 测量缺口 | yes/no | 构念测量不稳定或不适配新情境 |
| 方法缺口 | yes/no | 现有方法不能识别或捕捉关键现象 |
| 情境缺口 | yes/no | 新对象/新平台/新技术情境改变了原理论适用性 |
| 因果识别缺口 | yes/no | 现有研究只能相关，不能支持因果 |
