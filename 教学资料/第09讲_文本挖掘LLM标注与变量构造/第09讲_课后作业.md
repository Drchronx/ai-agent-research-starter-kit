# 第 09 讲课后作业

## 作业目标

用自己的研究方向或课程样例文本，构造至少 1 个可进入实证模型的文本变量。

## 提交文件夹

```text
姓名_第09讲_文本挖掘LLM标注与变量构造
```

## 必交文件

1. `textmining/text_data_inventory.xlsx`
2. `textmining/text_cleaning_plan.md`
3. `textmining/text_variable_definition.md`
4. `textmining/route_selection.md`
5. `textmining/annotation_codebook.md`
6. `textmining/annotation_sample.xlsx`
7. `textmining/feature_dictionary.xlsx`
8. `textmining/features.xlsx`
9. `textmining/reliability_report.md`
10. `textmining/variable_construction_report.md`
11. `qc/text_variable_audit.md`

## 数据要求

至少满足其一：

- 50 条以上评论文本。
- 20 篇以上公告、新闻或论文摘要。
- 10 份以上访谈或开放题回答。
- 5 篇以上年报、政策或长文档，并按段落切分。

如果使用真实用户、访谈或社媒数据，必须脱敏。

## 技术路线要求

至少完成一种路线：

- 分词 + 词频 / TF-IDF。
- 词典法变量。
- 情感分析变量。
- LDA / BERTopic 主题变量。
- LLM 标注变量。
- 监督分类变量。
- embedding 相似度变量。

## 300 字反思

回答：

```text
你的文本变量最可能被审稿人质疑什么？
你准备用哪些证据证明它不是随意构造出来的？
它不能支持哪些过度解释？
```

## 评分标准

| 项目 | 占比 |
|---|---:|
| 文本数据盘点和清洗计划 | 20% |
| 构念定义和技术路线匹配 | 25% |
| Codebook 和标注样本 | 20% |
| 可靠性与偏差审计 | 20% |
| 最终变量表和论文可用性 | 15% |

## 一票否决项

- 编造文本、标签、准确率、一致性指标。
- API key 写入文件或截图。
- 未脱敏使用敏感个人信息。
- 只有词云或主题词，没有变量构造。
- 把 LLM 标注当作无需人工复核的最终事实。
