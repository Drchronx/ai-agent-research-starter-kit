第八讲已覆盖：

- 数据分析、高级统计与因果推断的完整工作流。

- DID、event study、PSM、IV、RDD、DML 的适用场景、识别假设和不可过度声称的边界。
- DAG、混淆变量、坏控制、post-treatment variable 和因果语言审计。
- 结果表模板：描述统计、相关、主效应、机制、SEM/CFA、因果模型、稳健性、图形计划和写作追踪。

第十讲已覆盖：
