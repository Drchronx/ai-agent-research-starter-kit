# 第一次和 Agent 对话

## 目标

第一次不要让 Agent 直接写论文或跑数据。你要先让它理解项目、确认规则、说明下一步。

## 第一步：打开你的 Agent 工具

你可以使用 Codex、Claude Code 或其他本地 Agent 工具。打开后，确保当前工作目录是：

```text
<本项目路径>
```

如果不确定，可以直接把项目路径发给 Agent。

## 第二步：发送第一条提示词

复制下面这段：

```text
请进入 <本项目路径>\零基础教学包\07_示例科研项目模板。
先阅读 AGENTS.md 和 README.md。
不要修改任何文件，先告诉我：
1. 这个项目的目录结构；
2. 里面有哪些练习数据；
3. 我应该先做哪个练习；
4. 哪些文件不能修改。
```

## 第三步：判断回答是否合格

合格回答应该包含：

- 说明 `data/raw` 不能修改。
- 说明 `literature/pdfs` 用来放论文 PDF。
- 说明 `output` 用来放结果。
- 建议先做案例 1。

如果 Agent 一上来就要修改文件，你要打断它：

```text
先不要修改文件。请只做项目结构分析。
```

## 第四步：开始案例 1

然后去：

```text
04_五个完整练习案例\案例1_读一篇论文
```

按里面的说明继续。
