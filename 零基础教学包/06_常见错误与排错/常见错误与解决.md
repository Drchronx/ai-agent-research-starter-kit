# 常见错误与解决

## 1. Agent 说找不到文件

检查：

- 路径是否写完整。
- 路径是否加了引号。
- 文件是否真的存在。

正确示例：

```text
<本项目路径>\零基础教学包\07_示例科研项目模板
```

## 2. PowerShell 不能运行脚本

使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\08_脚本\check_environment.ps1
```

## 3. Python 没有安装

先检查：

```powershell
python --version
py --version
```

如果都不行，需要安装 Python 或 Anaconda。

## 4. 缺少 Python 包

如果看到 `ModuleNotFoundError`，说明缺包。

例如缺 pandas：

```powershell
python -m pip install pandas
```

如果有 requirements.txt：

```powershell
python -m pip install -r requirements.txt
```

## 5. Agent 编造了文献

处理方式：

```text
请停止生成。请把刚才所有引用逐条核验 DOI、作者、年份和期刊。无法核验的引用全部删除或标注“未核验”。
```

## 6. Agent 修改了不该修改的文件

以后先说：

```text
不要修改 raw 数据，不要删除文件。所有输出写入 output 文件夹。
```

## 7. 结果看不懂

让 Agent 解释：

```text
请用零基础能听懂的话解释每个输出文件是什么、怎么看、哪些结论不能下。
```
