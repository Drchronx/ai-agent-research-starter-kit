# 案例 10：量表开发与心理测量

目标：让新手学会从构念定义到量表选择、翻译回译、信效度、EFA/CFA、共同方法偏差和测量不变性。

## 需要 Skills

```text
scale-selection-adaptation
scale-reliability-validity
efa-cfa-measurement-model
common-method-bias-invariance
questionnaire-reporting-template
```

## 复制模块

```powershell
cd "<本项目路径>\本地Skills功能分类库"
powershell -ExecutionPolicy Bypass -File .\00_工具脚本\copy_skill_to_workspace.ps1 -Category 量表 -Workspace "D:\你的项目路径"
```

## 提示词

```text
请为“AI agent 信任、感知解释性、采纳意愿”三个构念建立测量方案。
请核验真实量表来源，输出构念定义、推荐量表、条目、响应锚点、翻译回译计划、预测试计划、信度效度分析、EFA/CFA、共同方法偏差、测量不变性和论文 Measures/Results 模板。
不要编造量表来源，不要为了提高 alpha 随意删题。
```

## 完成标准

- 有构念-条目-codebook。
- 有量表来源核验清单。
- 有信效度和 CFA 报告模板。
- 有共同方法偏差和测量不变性处理方案。
