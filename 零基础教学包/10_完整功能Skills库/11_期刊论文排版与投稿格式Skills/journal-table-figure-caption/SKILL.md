# Journal Table And Figure Caption

Use this skill to standardize visual-data labels and captions.

## Inputs

- Tables, figures, captions, notes, and callouts.
- Target journal rules for numbering, placement, caption style, notes, and appendix labels.

## Workflow

1. List every table, figure, appendix table, and appendix figure.
2. Verify sequential numbering and matching in-text callouts.
3. Apply target rules for labels, titles, captions, notes, abbreviations, and significance markers.
4. Flag missing captions, missing callouts, repeated numbers, or orphaned visuals.
5. Produce a visual-materials audit.

## Hard Constraints

- Do not change table data, figure data, statistical values, or image content.
- Do not rewrite the descriptive meaning of captions unless the user asks for writing revision.
- Preserve all notes and abbreviations, flagging unclear notes rather than deleting them.

## Output

```text
Standardized labels and captions:
Table and figure callout audit:
Missing or duplicate numbers:
Notes and abbreviation audit:
Manual review items:
```
