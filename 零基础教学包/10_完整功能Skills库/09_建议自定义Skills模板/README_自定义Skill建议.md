# 建议自定义 Skills 模板

当前课程资料对管理学、文本挖掘、实证分析支持较好，但对 EEG/ERP 与认知神经科学实验的支持还不够。建议后续优先自建以下 Skills。

## 1. `eeg-preprocessing`

用途：MNE-Python / EEGLAB 预处理标准化。

建议能力：
- 读取 `.set`、`.fif`、`.bdf`、`.edf`。
- 滤波、陷波、重参考。
- 坏道检测与插值。
- ICA 伪迹识别。
- Epoch、baseline、剔除异常 trial。
- 输出 HTML 质量报告。

## 2. `erp-analysis`

用途：ERP 成分分析与论文结果输出。

建议能力：
- 条件平均波形。
- N1、P2、N2、P3、LPP 等时间窗均值。
- 峰值、潜伏期、均值振幅。
- 重复测量 ANOVA 或线性混合模型。
- 输出波形图、地形图、统计表和 Methods/Results 英文模板。

## 3. `text-variable-construction`

用途：管理学文本挖掘变量构造。

建议能力：
- 年报、政策、评论、访谈文本清洗。
- 自定义词典与语义扩展。
- AI 关注度、前瞻性、情绪、信息含量、文本相似度。
- 人工抽样核验表。
- 输出变量构造说明和稳健性方案。

## 4. `ssci-introduction-writer`

用途：管理学/心理学 SSCI Introduction 写作。

建议能力：
- 任务-挑战-缺口-机制-贡献五段式。
- 避免文献堆砌。
- 强制理论、变量、研究设计对应。
- 输出中文逻辑版和英文投稿版。

## 5. `causal-robustness-checker`

用途：因果推断论文稳健性检查。

建议能力：
- 检查识别假设。
- 生成 placebo、替代变量、替代模型、聚类标准误、样本过滤、敏感性分析清单。
- 输出审稿人可能质疑点。
