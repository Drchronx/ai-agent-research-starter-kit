# HTML分析报告说明

## 输出文件

执行数据分析后，会生成一个完整的HTML分析报告文件：

```
analysis_output/
└── analysis_report.html    # HTML分析报告（包含所有结果和图表）
```

## HTML报告结构

### 1. 报告头部
- 标题：数据分析报告
- 响应式设计，支持桌面和移动设备浏览
- 美观的渐变色主题设计

### 2. 数据概览
展示数据的基本信息卡片：
- **数据维度**：行数 × 列数
- **数值型特征**：数值型特征数量
- **非数值型特征**：非数值型特征数量
- **缺失值总数**：数据中的缺失值数量

### 3. 描述性统计
完整的统计指标表格，包含每个数值型特征的：

| 指标 | 说明 |
|------|------|
| 特征名称 | 列名 |
| 计数 | 有效值数量（非缺失值） |
| 均值 | 平均值 |
| 标准差 | 数据离散程度 |
| 最小值 | 最小值 |
| 中位数 | 第50百分位数 |
| 最大值 | 最大值 |
| 偏度 | 分布偏斜程度 |
| 峰度 | 分布尖锐程度 |
| 缺失率(%) | 缺失值百分比 |

**解读要点**：
- **偏度（skewness）**：
  - 接近0：对称分布
  - 正值：右偏（长尾在右侧）
  - 负值：左偏（长尾在左侧）

- **峰度（kurtosis）**：
  - 接近0：正态分布
  - 正值：尖峰分布（更集中）
  - 负值：平坦分布（更分散）

### 4. 相关性分析

#### 相关性热力图
- 彩色矩阵图，直观展示特征间相关性
- **红色**：正相关
- **蓝色**：负相关
- **颜色深度**：相关强度
- 数值标注：每个格子显示具体相关系数值

#### 强相关特征对
自动识别并列出强相关特征对（|r| ≥ 0.7）：
- 特征对名称
- 相关系数值
- 颜色标记（红色=极强，黄色=强）

### 5. 特征分布

每个数值型特征生成两张图表并排显示：

**直方图（左侧）**：
- 显示数据分布形状
- X轴：特征值
- Y轴：频数
- 识别偏态和异常值
- 判断是否符合正态分布

**箱线图（右侧）**：
- 中线：中位数
- 箱体：Q1 到 Q3（中间50%的数据）
- 触须：1.5倍IQR范围
- 圆点：异常值

**解读要点**：
- 箱体越长，数据越分散
- 触须不对称，说明分布有偏
- 圆点数量反映异常值情况

### 6. 目标变量分析（可选）

如果指定了目标变量，会额外生成：
- 目标变量与其他特征的散点图
- 帮助识别与目标变量关系最密切的特征

## 中文字体支持

HTML报告内置中文字体支持：
- 自动检测并使用系统中文字体（微软雅黑、黑体、苹方等）
- 图表中的中文标签正确显示
- CSS字体栈包含多种中文备用字体

## 使用建议

### 智能体解读流程

1. **打开HTML报告**
   - 在浏览器中打开 `analysis_report.html`
   - 所有图表已嵌入，无需额外文件

2. **数据质量评估**
   - 查看数据概览卡片了解基本信息
   - 关注缺失值提醒
   - 检查描述性统计表中的缺失率

3. **特征分析**
   - 分析相关性热力图识别特征关系
   - 查看特征分布图理解数据分布
   - 关注偏度和峰度异常的特征

4. **业务洞察**
   - 结合统计结果和可视化图表
   - 提供数据驱动的建议
   - 指出潜在的数据质量问题

### 常见分析场景

**场景1：特征选择**
- 删除缺失率 > 50% 的特征
- 移除与其他特征高度相关（|r| > 0.9）的冗余特征
- 选择与目标变量相关性强的特征

**场景2：数据预处理**
- 对右偏严重的特征进行对数转换
- 对有异常值的特征进行Winsorize处理
- 对缺失值进行适当的填充

**场景3：模型诊断**
- 检查特征是否符合模型假设（如正态分布）
- 识别可能影响模型性能的异常值
- 评估特征工程效果

## 技术特性

- **单文件输出**：所有图表以base64编码嵌入HTML，无需额外文件
- **响应式设计**：适配桌面和移动设备
- **中文字体优化**：自动选择最佳中文字体
- **美观样式**：渐变色主题、卡片布局、阴影效果
- **交互友好**：表格支持鼠标悬停高亮
- **易于分享**：单个HTML文件可直接发送或上传
