# Project Dashboard Template

Use this structure for `00_project_dashboard/project_status.md`.

## Core Fields

- Project title.
- Current research question.
- Target paper or dissertation chapter.
- Current phase: idea, literature, design, data collection, analysis, writing, submission, revision.
- Active dataset.
- Active manuscript version.
- Current blockers.
- Next three priorities.

## Status Rules

- Completed means file evidence exists.
- In progress means work has started but output is not final.
- Blocked means a decision, file, approval, or external condition is missing.
- Deferred means intentionally postponed.
