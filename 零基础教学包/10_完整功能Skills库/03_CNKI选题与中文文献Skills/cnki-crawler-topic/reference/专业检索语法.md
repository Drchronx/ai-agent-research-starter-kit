# CNKI 专业检索语法速查

生成 CNKI 专业检索式前必须核对本文件。目标是输出能直接传给爬虫的 `query_pattern`，例如：

```text
TI='生态' and KY='生态文明' and (AU % '陈' + '王')
SU='北京' * '奥运' and FT='环境保护'
SU=('经济发展' + '可持续发展') * '转变' - '泡沫'
```

## 1. 最小语法

```text
字段代码 运算符 '检索值'
```

- 字段代码必须使用本文件第 2 节列出的字段。
- 检索值默认使用英文半角单引号 `'...'` 包裹。
- 逻辑连接可用 `and`、`or`、`not`；为了可读性，前后必须有空格。
- 复杂逻辑必须使用英文半角括号 `(...)` 明确优先级。
- 年份范围不要写进检索式，使用爬虫 CLI 的 `--start-year`、`--end-year`。

## 2. 可检索字段

| 代码 | 含义 | 常用写法 |
| --- | --- | --- |
| `SU` | 主题 | `SU='主题词'` |
| `TKA` | 篇关摘 | `TKA='词'` |
| `TI` | 篇名 | `TI='篇名词'` |
| `KY` | 关键词 | `KY='关键词'` |
| `AB` | 摘要 | `AB='摘要词'` |
| `CO` | 小标题 | `CO='小标题词'` |
| `FT` | 全文 | `FT='全文词'` |
| `AU` | 作者 | `AU='作者名'` |
| `FI` | 第一作者 | `FI='作者名'` |
| `RP` | 通讯作者 | `RP='作者名'` |
| `AF` | 作者单位 | `AF='单位名'` |
| `LY` | 期刊名称 | `LY='期刊名'` |
| `RF` | 参考文献 | `RF='参考文献词'` |
| `FU` | 基金 | `FU='基金名'` |
| `CLC` | 中图分类号 | `CLC='分类号'` |
| `SN` | ISSN | `SN='ISSN'` |
| `CN` | CN | `CN='CN号'` |
| `DOI` | DOI | `DOI='DOI'` |
| `QKLM` | 栏目信息 | `QKLM='栏目名'` |
| `FAF` | 第一单位 | `FAF='单位名'` |
| `CF` | 被引频次 | `CF>=1` |

## 3. 运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `=` | 包含/匹配指定检索值 | `TI='生态'` |
| `%` | 模糊/前缀类匹配，常用于作者姓氏等不完整值 | `AU % '陈' + '王'` |
| `>` | 大于 | `CF>0` |
| `<` | 小于 | `CF<10` |
| `>=` | 大于等于 | `CF>=1` |
| `<=` | 小于等于 | `CF<=100` |

注意：

- 主题检索使用新版写法 `SU='词'`。
- 被引频次 `CF` 可以用比较运算符；年份不在检索式中比较。

## 4. 逻辑与复合表达

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| `and` | 同时满足 | `TI='生态' and KY='生态文明'` |
| `or` | 任一满足 | `TI='生态' or KY='生态文明'` |
| `not` | 排除 | `TI='生态' not KY='污染'` |
| `*` | 同一字段表达式内同时包含 | `SU='北京' * '奥运'` |
| `+` | 同一字段表达式内包含任一 | `SU=('经济发展' + '可持续发展')` |
| `-` | 同一字段表达式内排除 | `SU='转变' - '泡沫'` |

字段内组合规则：

- `字段='A' * 'B'`：字段同时包含 A 和 B。
- `字段='A' + 'B'`：字段包含 A 或 B。
- `字段='A' - 'B'`：字段包含 A 且排除 B。
- `字段=('A' + 'B') * 'C' - 'D'`：先用括号表达字段内优先级。

## 5. 官方示例

```text
TI='生态' and KY='生态文明' and (AU % '陈' + '王')
```

检索篇名包含“生态”、关键词包含“生态文明”、作者为“陈”姓或“王”姓的文章。

```text
SU='北京' * '奥运' and FT='环境保护'
```

检索主题包含“北京”和“奥运”，且全文包含“环境保护”的文章。

```text
SU=('经济发展' + '可持续发展') * '转变' - '泡沫'
```

检索主题中与“经济发展”或“可持续发展”的“转变”相关内容，并排除“泡沫”。

## 6. 常用模板

```text
SU='主题词'
TI='篇名词'
KY='关键词'
AB='摘要词'
FT='全文词'
AU='作者名'
AF='作者单位'
LY='期刊名称'
FU='基金名'
CF>=1
SU='主题词' and AB='摘要词'
TI='篇名词' and (AU % '姓1' + '姓2')
SU=('词1' + '词2') * '词3' - '排除词'
```

年份范围用命令行参数，不写进检索式：

```powershell
python scripts/main.py "SU='主题词'" --start-year 2020 --end-year 2025
```

## 7. 生成前检查清单

- 字段代码是否只来自第 2 节的新字段表。
- 是否没有把年份条件写入专业检索式。
- 年份限制是否改用 `--start-year`、`--end-year`。
- 检索值是否使用英文半角单引号。
- `and`、`or`、`not` 前后是否有空格。
- 字段内 `*`、`+`、`-` 的优先级是否用英文半角括号明确。
- 输出给爬虫时只传检索式本身，不附加解释文字。
