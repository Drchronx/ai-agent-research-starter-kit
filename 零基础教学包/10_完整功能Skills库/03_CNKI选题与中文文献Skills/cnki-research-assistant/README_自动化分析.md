# 🚀 CNKI 自动化选题分析 - 一句话搞定

## 核心功能

**只需一句话，自动完成所有分析：**

```bash
python scripts/auto_analyzer.py "你的选题关键词"
```

---

## 使用示例

### 示例 1：完整分析（推荐）


## 分析报告内容

### 1. 执行摘要
- 热度评估（⭐⭐⭐⭐ 4.0/5）
- 发表空间（⭐⭐⭐⭐ 4.5/5）
- 竞争程度（激烈）
- 核心发现（峰值年份、主导学科、推荐期刊）

### 2. 热点扫描
- CNKI 热榜周榜/月榜排名
- 在榜天数
- 状态识别（new/continuing/returning）

### 3. 趋势评估
- **年度趋势图**：峰值年份、近三年占比、趋势判断
- **学科分布图**：覆盖学科数、首位学科及占比
- **期刊格局图**：覆盖期刊数、集中度、发表空间
- **机构分布图**：头部研究机构
- **基金分布图**：主要资助方向
- **主题分布图**：研究热点主题 Top 10

### 4. 文献调研
- 抓取文献数（230+ 篇）
- 高被引文献识别
- 核心作者识别
- 文献统计信息（平均被引、平均下载、年份范围）

### 5. 期刊推荐（CSSCI）
- 匹配度 Top 10 期刊
- 期刊征稿方向契合点
- 期刊级别（核心/扩展）
- 投稿策略建议

### 6. 研究空白分析（6 个维度）

| 维度 | 分析内容 | 输出示例 |
|------|---------|---------|
| **关键词共现** | 识别未充分研究的关键词组合 | "高质量发展 + 供应链韧性 研究较少" |
| **主题聚类** | 研究主题分布 | 主题集中度分析 |
| **研究方法** | 实证/理论/案例/仿真等方法多样性 | "缺乏因果推断方法" |
| **机构合作** | 研究机构分布 | "头部机构集中度高" |
| **基金资助** | 资助方向分析 | "主要资助方向：国家社科基金" |
| **时间趋势** | 年度文献量变化 | "近两年文献激增，处于爆发期" |

### 7. 综合建议
- 选题可行性评估（热度/发表空间/竞争程度）
- 潜在切入点（学科交叉/方法创新/视角创新）
- 投稿策略（首选期刊/备选期刊/投稿时机）

## 技术细节

### 文献抓取策略
- **检索式**：`SU=('关键词')`（主题字段）
- **排序**：按被引频次（CF），确保权威文献
- **页数**：5 页（约 250 篇）
- **去重**：基于标题哈希去重
- **保存**：自动保存到 PostgreSQL 数据库

### 深度分析配置
- **多排序抓取**：支持 DFR/CF/PT/ZH 四种排序
- **研究空白**：6 个维度自动识别
- **期刊匹配**：0.4×学科匹配 + 0.4×选题相似度 + 0.2×级别系数
- **中文字体**：STSong.TTF（已适配）

### 输出格式
- **报告**：Markdown 格式，支持飞书文档
- **图表**：PNG 格式，180 DPI，中文字体
- **路径**：`reports/auto/关键词_分析报告_时间戳.md`

## 故障排查

### 问题 1：文献抓取失败

**症状**：抓取结果为 0

**解决**：
```bash
# 1. 检查代理
python /root/.openclaw/skills/cnki-crawler/scripts/proxy_check.py

# 2. 验证检索式
python /root/.openclaw/skills/cnki-crawler/scripts/validate_query.py "SU=('数字经济')"
```

### 问题 2：图表中文乱码

**症状**：图表中文字符显示为方框

**解决**：
```bash
# 检查字体文件
ls -la /root/.openclaw/workspace-hotspot/skills/cnki-research-assistant/data/STSONG.TTF
```

### 问题 3：分析结果为空

**症状**：报告中所有模块都显示失败

**解决**：
```bash
# 检查数据库连接
PGPASSWORD=123456 psql -h localhost -U cnki_user -d cnki_db -c "SELECT COUNT(*) FROM cnki_papers;"
```
