# 常用提示词模板

## 1. 让 Agent 先理解项目

```text
请进入 [项目路径]，先阅读 AGENTS.md 和 README.md。不要修改文件，先告诉我这个项目的目录结构、已有材料和你建议的下一步。
```

## 2. 读论文

```text
请读取 [PDF路径]，输出结构化论文笔记。必须包括研究问题、理论、变量、样本、方法、发现、局限和对我研究的启发。不要编造 DOI 或引用。
```

## 3. 建文献矩阵

```text
请读取 literature/pdfs 中的论文，建立文献矩阵，输出 xlsx 和 md。找不到的信息写“未报告”，不要编造。
```

## 4. 做数据分析

```text
请分析 data/raw/[文件名]。不要修改 raw 数据。先做数据质量检查，再清洗，最后输出描述统计、相关矩阵、图表和基础模型结果。
```

## 5. 做文本挖掘

```text
请对 [文件名] 的 [文本列] 做文本分析：清洗、分词、词频、TF-IDF、情感分析，并输出可用于后续回归的变量表。
```

## 6. 写 Introduction

```text
请基于我的研究问题和文献矩阵写 Introduction。要求问题意识清楚，理论机制具体，不要文献堆砌，不要编造引用。
```

## 7. 审稿检查

```text
请以严苛审稿人视角检查这篇论文，优先指出会导致拒稿的问题：理论机制、方法识别、结果解释、引用真实性、贡献夸大。
```

## 8. 设计情景实验

```text
请围绕[研究问题]设计一个顶刊风格情景实验。先用 scenario-experiment-benchmark-mining 找真实论文范式，不要编造引用；再用 scenario-experiment-design 输出理论机制、实验条件、刺激材料、操纵检验、真实感检验、混淆检验、预实验和主实验方案。
```

## 9. 分析情景实验数据

```text
请用 scenario-experiment-analysis 分析 data/raw/[文件名]。不要修改 raw 数据。请先做数据质量、排除规则、随机化检查、操纵检验、信度、主效应/交互/中介/调节分析、效应量和稳健性，输出结果表和可写进论文的结果解释。
```

## 10. 汇报情景实验结果

```text
请用 scenario-experiment-reporting 把下面的分析结果写成 JCR/JCP/JM/JAP/ISR 风格的 Method 和 Results。必须报告样本、排除、随机分配、操纵检验、量表信度、估计值、SE/CI、精确 p 值、效应量、图表和透明性说明。
```

## 11. 要求输出到指定位置

```text
所有输出请写入 [输出文件夹]。请列出每个输出文件的用途。
```

## 12. 论文排版和盲审匿名化

```text
请按[目标期刊/APA第7版]对我的稿件做投稿前格式审计。需要检查扉页、摘要、标题层级、正文引用、参考文献、图表标题、统计格式、脚注尾注、布局和盲审匿名化。只做格式和结构处理，不要改动任何数值、统计结果或原始学术主张。
```

## 13. EEG/ERP 实验流程

```text
请为[研究问题]设计 EEG/ERP 研究流程。输出实验范式、事件码、试次数、预处理计划、ERP/频域/连接/机器学习分析计划、QC 表、图表计划和 Methods/Results 模板。不要覆盖 raw EEG 数据。
```

## 14. 量表和心理测量

```text
请为我的变量选择真实可核验量表，并设计翻译回译、预测试、信度、效度、EFA/CFA、共同方法偏差和测量不变性分析。不要编造量表来源，不要为了提高 alpha 随意删题。
```

## 15. 高级统计和因果推断

```text
请判断我的研究设计适合中介调节、SEM、多层模型、DID、PSM、IV、RDD、DML 还是只能做相关分析。输出可支持的结论、不能说的结论、模型公式、稳健性、结果表和 Results 写法。
```

## 16. BCI 脑电智能建模

```text
请围绕[BCI任务]构建脑电智能建模流程。先规范 subject/session/trial/window/label 和 split 单位，再设计特征、传统机器学习基线、深度学习模型、跨被试泛化、防泄漏审计和结果汇报。不要把 trial-level random split 写成 cross-subject，不要在全数据上做标准化、CSP、PCA 或特征选择后再交叉验证。
```

## 17. 科研项目管理

```text
请为我的课题[课题名]建立长期科研项目管理结构。需要生成 AGENTS.md、project_status.md、research_log.md、data_lineage.csv、manuscript_versions.md、submission_tracker.csv 和 weekly_plan.md。以后每次任务开始先读项目状态，任务结束更新日志和下一步。
```

## 18. 要求不要直接执行

```text
先不要修改文件，也不要运行代码。请先给出计划、需要确认的问题和可能风险。
```
