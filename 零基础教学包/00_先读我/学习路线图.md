# 学习路线图

这份路线图面向完全新手，但目标不是只学简化功能，而是逐步掌握完整 131 个科研 Skills。

## 第 0 关：知道自己在做什么

目标：知道 Agent、Skill、MCP、Subagent 是什么。

阅读：

- `01_认识AI_Agent/零基础术语表.md`
- `01_认识AI_Agent/AI_Agent到底是什么.md`

完成标准：

- 能说出普通聊天 AI 和本地 Agent 的区别。
- 知道 Skill 是“封装好的科研工作流程”。
- 知道完整 Skills 库在 `10_完整功能Skills库`。

## 第 1 关：会打开命令行

目标：能在 Windows 打开 PowerShell，进入指定目录，运行脚本。

阅读：

- `02_环境与部署/PowerShell零基础.md`

完成标准：

- 会运行 `cd "<本项目路径>\零基础教学包"`。
- 会运行 `powershell -ExecutionPolicy Bypass -File .\08_脚本\check_environment.ps1`。
- 会运行 `powershell -ExecutionPolicy Bypass -File .\08_脚本\check_full_skills_library.ps1`。

## 第 2 关：先学会按需复制 Skills，跑通基本动作

目标：先把需要的科研 Skills 从本地分类库复制到项目工作区，避免一开始把 131 个功能全部装进 Codex 根目录。

运行：

```powershell
cd "<本项目路径>\本地Skills功能分类库"
powershell -ExecutionPolicy Bypass -File .\00_工具脚本\copy_skill_to_workspace.ps1 -SkillName pdf -Workspace "D:\你的项目路径" -DryRun
```

完成标准：

- 知道怎么用 `copy_skill_to_workspace.ps1` 复制单个 Skill。
- 知道默认复制到 `目标工作区\skills`。
- 能完成 14 个练习案例。

## 第 3 关：完成基础练习

按顺序做：

1. 读一篇论文。
2. 建立文献矩阵。
3. 分析 Excel/CSV 数据。
4. 做文本挖掘入门。
5. 写论文段落并审稿。
6. AMiner 与 AI4Scholar 真实学术平台接入。
7. 情景实验设计、分析和结果汇报。

完成标准：

- 每个案例都有输出文件。
- 你知道输出文件放在哪里。
- 你知道哪些结果需要人工核验。

## 第 4 关：按需复制完整 Skills

目标：让项目工作区按任务获得需要的 Skills，而不是把所有 Skills 装进 Codex 根目录。

先预览：

```powershell
powershell -ExecutionPolicy Bypass -File .\00_工具脚本\copy_skill_to_workspace.ps1 -Category 文献 -Workspace "D:\你的项目路径" -DryRun
```

确认后复制：

```powershell
powershell -ExecutionPolicy Bypass -File .\00_工具脚本\copy_skill_to_workspace.ps1 -Category 文献 -Workspace "D:\你的项目路径"
```

完成标准：

- 全部 131 个 Skills 都在 `<本项目路径>\本地Skills功能分类库` 按功能分类保存。
- 你能按 Skill 名称或功能分类复制到项目工作区。
- 你能说出 17 大类功能分别适合什么任务。

## 第 5 关：按模块学习完整功能

建议顺序：

1. 文档处理：PDF、DOCX、XLSX、PPTX、Markdown。
2. 文献检索、综述和引用核验。
3. AMiner 和 AI4Scholar 真实学术平台：AI4Scholar 现在按论文搜索、详情核验、引用网络、作者画像、论文推荐、全文阅读、自动加引用、科研绘图、MCP/OpenClaw 部署拆成专项 Skills。
4. CNKI 中文文献与选题。
5. 数据整合、实证分析和机器学习。
6. 文本挖掘与 NLP。
7. 论文写作、审稿和投稿。
8. MCP、浏览器自动化和自定义 Skill。
9. 科学图、PPT、poster 和论文网页。
10. 情景实验顶刊范式挖掘、刺激设计、预实验、主实验分析和结果汇报。
11. 论文排版、引用参考文献、图表标题、统计格式和盲审匿名化。
12. EEG/ERP 实验设计、预处理、ERP/频域/连接分析和脑电机器学习。
13. BCI 脑电智能建模、跨被试泛化、深度学习、在线解码和防泄漏评估。
14. 量表选择、信效度、EFA/CFA、共同方法偏差和测量不变性。
15. 高级统计、SEM、多层模型和准实验因果推断。
16. 科研项目管理、论文版本控制、数据血缘和投稿返修追踪。
17. Zotero / Obsidian 长期知识库、论文卡片、理论-变量-方法矩阵、研究问题知识图谱和可复用启发沉淀。

完成标准：

- 每个模块至少完成一个真实或模拟任务。
- 每个任务都能写清楚：输入是什么、用哪些 Skills、输出放在哪里、哪些结论需要人工核验。

## 第 6 关：迁移到自己的课题

目标：把练习流程换成你的真实论文项目。

动作：

- 复制 `07_示例科研项目模板`。
- 改名为你的课题名。
- 把真实 PDF 放入 `literature/pdfs`。
- 把真实数据放入 `data/raw`。
- 修改项目中的 `AGENTS.md`。
- 每次让 Agent 工作前，要求它先读 `AGENTS.md`，再判断应使用哪些 Skills。
