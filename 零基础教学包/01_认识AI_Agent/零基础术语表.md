# 零基础术语表

## Agent

能使用工具完成任务的 AI 助手。它不仅回答，还能读文件、跑命令、写文件。

## Skill

一个专项技能包。里面通常有：

- `SKILL.md`：说明这个技能怎么用。
- `scripts/`：可执行脚本。
- `references/`：方法说明。
- `assets/`：模板和示例。

## SKILL.md

Skill 的说明书。Agent 会先看这里，判断是否要使用这个 Skill。

## 触发词

让 Agent 想到某个 Skill 的关键词。比如你说“文献综述”，可能触发 `literature-review`。

## 部署

把 Skill 文件夹复制到 Agent 能识别的位置。

## 技能目录

存放 Skills 的文件夹。例如：

```text
C:\Users\<用户名>\.codex\skills
```

## PowerShell

Windows 的命令行工具。你可以用它进入文件夹、运行脚本、安装依赖。

## 环境变量

电脑里保存配置的地方。API key 应该放这里，而不是写进文档。

## requirements.txt

Python 依赖清单。运行下面命令可以安装：

```powershell
python -m pip install -r requirements.txt
```

## raw 数据

原始数据。不能覆盖、不能直接修改。

## processed 数据

清洗后的数据，可以用于分析。

## 文献矩阵

把多篇论文的重要信息整理成表格，例如作者、理论、变量、方法、发现、局限。

## BibTeX

学术引用格式文件，通常是 `references.bib`。
